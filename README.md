# paperfire（《纸火》）

> Working title **《纸火》 / Paper Fire** — a Chinese eerie folk **management–survival** PC short game: daytime yang (mortal) business, nighttime weird business. Management primary, survival secondary.

中式诡异民俗单机经营游戏（暂名《纸火》）。PC 小品。

**已拍板口径**：经营为主、生存为辅（高压主要挂在夜里履约）；**白天阳间生意 / 晚上诡异生意**；调性为冷幽默 + 偶发高压；主角为外乡接手祖业纸扎铺。

## 一句话

你在一座正在「现代化」的小镇上经营纸扎铺与阴事中介：白天接阳间红白事与镇民订单；天黑后另开一本账接诡异生意。两边的材料、规矩、人情与口碑会互相拖累，也会互相救命。

## 玩家在玩什么

- **主循环（经营）**：接单（红白事纸扎、安神符、搬家净宅、寻物、送行等）→ 备料与工艺 → 交期与口碑 → 扩建铺面、雇帮工、打通关系网。日夜都是「接单 → 履约 → 结算」；差别在客户、规则强度与履约场面。
- **辅循环（生存）**：禁忌表绑在订单上；夜里履约是短事件式交付（送客、封门、对簿、安纸人等），用规矩、道具与人情化解，而不是硬砍怪。失败会砸经营资产（伙计拒夜班、客流、铺面议论）。
- **会话节奏**：白天决策密、反馈快；夜里短、压迫强；失败可回白天用经营补救。整体是会算计的小镇经营，不是长线肉鸽挂机。

## 诡异感怎么进系统

| 来源 | 进玩法的方式 |
| --- | --- |
| 民俗禁忌 | 订单规则书：月份、属相、方位、口头禅等改成功率与夜间遭遇 |
| 志怪神鬼 | 客户不全是活人；有的单要「两套账」（阳面交付 + 阴面条件） |
| 都市传说 / 现代乡土 | 路通了、手机有了、庙拆了；旧规矩与短视频谣言抢解释权；在「科学说法」与「老话」之间选成本 |

气质参考（借味不照搬）：**鬼吹灯**的「规矩当系统、信息差致命」；**纸嫁衣**的纸扎、婚葬与乡土空间情绪。本作把探险改成**坐店经营**，把解谜恐怖改成**订单与禁忌的经营压力**。

## 差异化

1. 恐怖来自「接不接这单、怎么交差」，不是走廊追逃。
2. 资源同时是钱、材料、人情与「洁净」；生存失败砸的是经营资产。
3. 黄历、纸扎品类、镇民称呼是 UI 与关卡语言，不只做皮肤。

## 体量边界（小品）

- 主线约 **8–15 小时**可通；可加一周一周目「禁忌更严」，不做赛季。
- 内容块：1 个小镇 + 3–4 个节气/庙会节点 + 约 20–30 种订单模板 + 若干夜间事件卡。
- **本版不做**：大型开放地图、重度战斗、联机、长线 live ops。
- 尺度偏发忌、盯梢、错身、纸人自行；默认回避过度血腥与明确宗教仪轨照搬。
