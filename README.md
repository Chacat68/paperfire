# paperfire《纸火》

> Working title **《纸火》 / Paper Fire** — a Chinese eerie folk **management–survival** PC short game: daytime yang (mortal) business, nighttime weird business. Management primary, survival secondary.

中式诡异民俗单机经营游戏（暂名《纸火》）。PC 小品。

**已拍板口径**：经营为主、生存为辅；**每天分成日夜：白天是活人的需求 / 晚上是诡异的需求（且暗藏骗你出门杀掉的诱杀诡）**；调性为冷幽默 + 偶发高压；背景为**玩家穿越进诡异游戏世界，初始绑定经营系统，经营纸扎铺赚取奖励以兑换生存物资**；视觉采用 **2D 黑白水墨 · 民国线描（一点朱砂）** 与动态诡异微事件，纯 HTML5 Canvas 离线即开即玩。

## 一句话

你意外穿越进一座正在「现代化」的诡异小镇游戏里，初始系统把一间老纸扎铺交给你打理：**白天满足活人的需求**（红白事纸扎、搬家净宅与街坊委托，最多只是日常麻烦），**晚上满足诡异的需求**（逐位听清来意，识破企图骗你出门杀掉的诱杀诡，并按禁忌履约正规诡客）；赚取系统「纸火点」兑换在这个世界活下去的生存口粮、镇煞符箓与铺面升级。

## 现行可玩试玩特性（V0.4.0）

- **五幕水墨连环画开场演绎**：首次开局以五幕黑白水墨连环画交代穿越入镇、绑定纸火系统与日夜规矩的来龙去脉（可于右上角「设置」随时重看）。
- **实时时辰与倒计时 HUD**：界面不显示「第几天」，左上角仅展示当天十二时辰与时刻，并配备实时倒计时进度条（弹窗打开时自动暂停，归零自动切入下一时段）。
- **角色登场 + 身侧连环画台词气泡**：选中白天或夜晚任意一张委托卡，对应角色从木门步入柜台前，身侧弹出民国连环画对白气泡（白天宣纸底 / 夜晚墨黑朱砂底）逐句讲述经过，听完后再决定接单、识破拒接或换听别家。
- **夜间真假诡异辨伪与诱杀陷阱**：每晚夜账同时出现正规诡异单与暗藏破绽的「诱杀单」（冒充熟人、假办事员、黑屏复读语音、反向湿脚印挑夫、假系统使者等）；误信出门将触发专属诱杀死亡结局（持「护身替纸人」可自燃替死一次），识破拒接则获 `+6 纸火点` 与 `阴气 −1`。
- **独立「外出街巷」水墨老镇外景**：白天可点击右侧 `外出街巷 (G)` 或直接点击铺子老木门，切入全屏手绘民国青石老镇街景（镇集杂货、林氏诊所、柳记裁缝铺、老槐街口），向柳裁缝打听禁忌时由其身侧气泡直接点破今夜破绽。
- **卡牌化柜台与「卡牌兑换阁」**：白天/夜晚委托、街巷地点与收尾铺务全面卡牌化，流程控制（`外出街巷`、`系统兑换`、`落锁入夜`、`落闩收摊`）归入右侧独立按钮区；点击 `系统兑换 (S)` 打开三类分区（生存补给 / 镇煞符箓 / 铺面永久升级）、全部带专属图标的卡牌兑换阁。
- **拟真民国线装双开老账本**：按 `L` 或点击顶栏「日账/夜账」摊开 940px 宽幅双开宣纸朱丝栏线装账本，支持顶部书签、底部翻页按钮与 `← / →` 方向键逐日翻阅往日归档与今日流水。
- **每日收尾「铺务整理」决策 & 天明存活签核仪式**：每晚结账后必须先在「扫灰焚香净铺 / 收拾残纸守铺 / 雇佣或安抚小栓 / 动用人情卡 / 洗把柄 / 预约明晚歇铺」中选定 1 项收尾铺务决策，方解锁「迎接明日天明」；跨天时弹出带朱砂落印动效的「鸡鸣卯时 · 今天成功活下来了」存活签核仪式弹窗。
- **完整 D1–D15 周期 & 动态诡异微事件**：涵盖 3 场 3 回合顶格高压夜（D6 无轿纸新娘 / D10 百戏游神 / D13 空椅听戏诡）、D15 系统终审多分支结局、7 类克制型动态诡异微事件与 Web Audio 拟音（右上角「设置 (O)」收纳静音开关、重看序幕与 9 段卷宗选段）。

## 本地运行与校验

```bash
npm install
npm run dev        # 启动本地 Vite 开发服务器
npm test           # 运行 Vitest 引擎单元测试（18/18）
npm run typecheck  # TypeScript 类型检查
npm run build      # 生产构建（输出至 dist/）
```
