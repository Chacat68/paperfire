# 《纸火》（暂名）概念一页纸

> 可改稿。用途：立项自用。平台：PC。体量：小品（大约数周可通关）。循环：经营为主，生存为辅。诡异感：民俗禁忌 × 志怪 × 现代乡土/都市传说。

## 一句话

你在一座正在「现代化」的小镇上经营纸扎铺与阴事中介：白天接单、进货、守规矩；晚上用白天攒下的规矩与人情，熬过因犯忌或接错单而缠上来的事。

## 玩家到底在玩什么

- **主循环（经营）**：接单（红白事纸扎、安神符、搬家净宅、寻物、送行）→ 备料与工艺选择 → 交期与口碑 → 用收入扩建铺面、雇帮工、打通镇里关系网。
- **辅循环（生存）**：每笔单都绑着禁忌表（能说/不能说、能做/不能做、黄道与月份）。犯规或知情不报会抬高「阴气值」；夜里触发短事件（守夜、送客、封门、对簿），用道具、人情与正确仪轨化解，而不是硬砍怪。
- **会话节奏**：白天经营决策密、反馈快；夜里事件短、压迫强、失败可回白天用经营补救。整体偏「会算计的小镇经营」，不是长线肉鸽挂机。

## 诡异感怎么进系统（不是贴皮）

| 来源 | 进玩法的方式 |
| --- | --- |
| 民俗禁忌 | 订单规则书：月份、属相、方位、口头禅都会改成功率和夜间遭遇 |
| 志怪神鬼 | 客户不全是活人；有的单要「两套账」：阳面交付物 + 阴面条件 |
| 都市传说/现代乡土 | 背景是路通了、手机有了、庙拆了；旧规矩和短视频谣言抢解释权，玩家要在「科学说法」和「老话」之间选成本 |

气质上：鬼吹灯的「用知识活命、同伴与规矩比胆子重要」；纸嫁衣的「红白喜事、纸人纸马、家庭/姻缘咒与乡土空间」。本作把探险队改成**坐店经营**，把解谜恐怖改成**订单与禁忌的经营压力**。

## 差异化（相对常见恐怖/经营）

1. 恐怖来自「接不接这单、怎么交差」，不是走廊追逃。
2. 资源同时是钱、材料、人情和「洁净」；生存失败会砸经营资产（伙计跑了、铺面被贴封、镇民不来）。
3. 中式符号服务规则可读性：黄历、纸扎品类、镇民称呼，都是 UI 与关卡语言，避免只做皮肤。

## 体量边界（小品）

- **目标时长**：主线约 8–15 小时可通；可加一周一周目的「禁忌更严」难度，不做赛季。
- **内容块**：1 个小镇 + 3–4 个节气/庙会节点 + 约 20–30 种订单模板 + 若干夜间事件卡。
- **不做（本版）**：大型开放地图、重度战斗、联机、长线 live ops。

## 参考怎么用（避免照搬）

- **鬼吹灯**：借「规矩当系统」「信息差致命」；不借盗墓闯阵主循环。
- **纸嫁衣**：借纸扎、婚葬、乡土空间与家庭债的情绪；不做成纯章节解谜 AVG，经营仍是主菜。

## 已拍板

1. **调性**：冷幽默 + 偶发高压（文案与夜间事件密度按此）。
2. **主角身份**：外乡接手祖业（教程与叙事密度按此）。
3. **尺度**：诡异偏「发忌、盯梢、错身、纸人自行」，默认回避过度血腥与明确宗教仪轨照搬；若要加烈度再单开一版。
