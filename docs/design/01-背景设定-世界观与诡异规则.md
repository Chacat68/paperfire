## 1. 一句话世界与玩家位置

有一座正在「现代化」的小镇：路通了，手机有了，庙拆了一半，红白事还是要办。你从外乡回来，接手长辈留下的纸扎铺——柜台白天卖正经彩头与纸货，账本翻到夜页，另开一栏谁都不肯当众念出来的生意。

你不是除魔人，也不是探险队长。你是**坐店的**：接单、备料、交差、还人情。镇里老人假装不知道夜账；年轻人催你别搞封建；同一条街，夜里又有人把红包塞进你袖口。

玩家位置一句话：**外乡接手祖业的纸扎师傅，白天维持正常铺面，夜里用规矩与人情把阴事办完——办砸了，砸的是铺子和人，不是血条。**

## 2. 地理 / 社会：镇子气质、阳间日常、权力与人情

### 2.1 镇子气质（玩家走街能感到的）

镇不大，一圈走下来总能撞见同一批脸。新铺面的灯箱和旧屋檐挤在一块：快递点贴着「禁止封建迷信」的褪色告示，隔壁香火味却不肯散。拆迁工地围挡上刷着标语，夜里风一刮，纸钱边角会从缝里飘出来——没人承认那是谁放的。

气质关键词：**现代乡土正在互相抢解释权**。短视频、工作证、黄历、保温袋，四种「权威」同时有效。玩家要学会听人说话的场合：同样一句话，在居委会门口和后巷里，意思差一整本账。

### 2.2 阳间日常秩序

白天的镇，表面秩序清楚：

- **红白事仍要办**：纸扎、花圈、寿衣店那一套没消失，只是年轻人更爱说「好看一点」「能不能快点」。
- **合规话术常在**：居委会、宣传栏、「净宅」也可以包装成「卫生与心理安慰」。
- **人情走明路**：介绍邻居、送点吃的、帮着圆一句场——这些会让你的阳间客源活着。
- **科学说法是保护色**：医馆把符当安慰剂收得认真；阿杰张口就要拍。你点头可以，犯规的成本多半是钱和闲话，不一定立刻出事。

阳间不是「无诡异」，而是**诡异被礼貌地压在台面下**。轻忌像乡俗彩头：属相日别交白事货、客人面前别把死气当笑话说——犯了，多半扣信任与现金，很少当场把铺子变成鬼屋。

### 2.3 权力与人情（谁说了算）

镇里没有魔王，只有几套叠在一起的权力：

| 面孔 | 白天怎么算数 | 夜里怎么算数 |
| --- | --- | --- |
| 支书一类 | 通知、抽查、合规单 | 便装、红包、不敢立案的事 |
| 老人 / 旧手艺人 | 挑剔工艺、闲话毁誉 | 仪轨怎么走、旧愿欠谁 |
| 邻里中介（如陈婶） | 介绍单、抬镇民信任 | 偶尔托你瞒家里人的小阴事 |
| 同行（对门香火店等） | 抢单压价、笑脸报价 | 甩锅、共背、脏料渠道 |
| 「那侧」与夜口碑 | 几乎不公开 | 老人认可、同行忌惮、纸马童引荐 |

人情在这镇不是 RPG 好感条，是**叫得动谁、谁肯替你顶一句**。抽象人情池存在于规则里，但玩家记得住的是具名：叫柳裁缝来、让陈婶圆场、支书盖一次章。

外乡身份是叙事滤镜：别人用「你爷爷从前……」「你们城里人……」给你塞信息；教程密度靠账本批注与老人点拨，不做长身世 AVG。

## 3. 日与夜：同一张脸两套账；「生意」各意味什么

### 3.1 为什么要两套账

太阳底下，纸扎铺是合法的民俗生意：红白纸货、安神符、搬家净宅、寻物、阳面送行。交期、彩头、能不能拍照——规矩轻，反馈快，冷幽默多出在柜台圆场。

天一黑，账本翻到夜页。同一间铺、同一批材料，换一本规则书：送行要送到「那边认账」、安魂要分清真假客、两套账要补阴面条件、纸人自行要善后、有些东西「不该寻」。报酬更高，禁忌更重，偶发高压挂在**履约现场**，而不是挂在「夜里纯挨吓」的被动时段。

> 相对《概念一页纸》旧句：夜里曾写成「因犯忌缠上来的事」。**现行已拍板口径**（核心循环修订）：**白天阳间生意 / 晚上诡异生意**；生存压力是夜履约里的辅循环。本稿按修订口径写。

### 3.2 同一张脸，两套社会面具

这是本镇最大的故事发动机。玩家认人靠口头禅、物件、站位，不靠好感度数。

| 白天玩家看见 | 夜里玩家看见 | 世界在说什么 |
| --- | --- | --- |
| 反封建通知、合规净宅 | 便装塞红包、按老规矩办 | 权力也怕立案；现代化是白天的戏服 |
| 要拍摄、要好看、科学说法 | 求删图、求安神 | 镜头会把不该看见的留住 |
| 热心红白事、先问你吃了没 | 托你别跟家里人说 | 温情里也有小阴事 |
| 把符当安慰剂认真收钱 | 拒诊的「病人」转到你夜账 | 科学口吻与装瞎可以共存 |
| 纸马旁像摆设的「童」 | 接待、带路、引夜单 | 铺子里谁算活人——持续疑问 |

**生意在两边各意味什么：**

- **阳间生意**：维持「正常铺面」人设；攒钱、料、洁净、镇民信任；为夜里买门票（正料、人情、敢接的胆量）。
- **诡异生意**：私下履约；涨夜口碑与老人认可；搞砸会外溢到次日阳间——伙计怕、客少、贴条议论。拒单也有代价：有些单是「被盯」的，不理它，它会记你一笔。

日接夜交（bridge）在世界叙事上说得通：白天收订金、开一张「净宅宣传」或「安神」的阳面合同；夜里才办真阴事。同一人、同一事，两套说法——玩家两边都点头，冷幽默与凉意同时成立。

**【暂定/可改】** bridge 出现频率、是否与「被盯」算一类——见 §8。

## 4. 诡异规则（核心）：规矩、禁忌、阴气与洁净

这一节写**玩家在世界里如何理解规则**，不重复整本禁忌系统文。细则对模块 `04` / `05`，数值一律【示例】。

### 4.1 什么算「规矩」

规矩不是技能树名称，是**这镇办阴事时，事情肯不肯认账的手续**。

- 阳间轻忌：像乡俗与彩头。犯规 → 多扣钱与镇民信任；日末可能略抬阴气【示例】。
- 夜页重忌：像真规则书。不可录音、不可第三人在场、不可乱叫真名、有的月份不能动某类活——可知条目接单时能看见；隐藏条目要打听或履约中途才翻出来。**不知比硬闯更致命**（信息差气质，借鬼吹灯的「规矩保命」，不借盗墓主循环）。

规矩分档，玩家体感是「你有没有资格走正统」：

| 档 | 世界说法 | 玩家感到 |
| --- | --- | --- |
| 歪办 | 总能糊弄，邪门 | 能压一点局面，但容易把阴气惹上来 |
| 正统 | 洁净够、老人教过 | 履约时像样地压局面 |
| 老人认可 | 夜口碑到了一定份上 | 特定事少踩隐忌、或再轻一档 |

**【示例】** 脏铺（洁净过低）时，正统仪轨像蒙了灰——你不是「不能玩」，是只剩歪办，自己清楚风险。

### 4.2 禁忌从哪来

禁忌来源叠三层，玩家不必背百科，但文案要让人感到层次：

1. **民俗层**：黄历、属相、方位、口头禅——白天也管用，夜里更狠。
2. **行业层**：纸扎 / 送行 / 安魂这一行代代忌的「交法」；账本旧注、柳裁缝点拨、长辈声音（不出影）是外乡的入门。
3. **现场层**：这单这个事主特有的条件（已传播的图要收回说法、拒诊转介来的怪客……）。隐藏忌多半藏在这里。

尺度已拍板方向：发忌、盯梢、错身、纸人自行；回避过度血腥与明确宗教仪轨照搬。

### 4.3 阴气在世界里怎么被理解

阴气**不是血条**。它是「铺子与街上不对劲的浓度」：

- 灯色发冷、纸灰微扬、日客台词发虚、夜单变密变凶。
- 守规矩的成功履约，像把窗户开一道缝，能降一点。
- 抬起来的常见原因：夜错规矩、脏料硬上、拒被盯、履约失败；阳间轻忌只轻抬。

紧张态的叙事说法【示例】：阴气偏高 → 镇虚；再高 → 炸街（强制碰上更凶的候选）；顶到头 → 坏结局检定之一。玩家应感到**街上在议论你**，而不是 HUD 数字在尖叫。

### 4.4 洁净在世界里怎么被理解

洁净是料与铺的「清气」：精工累积、正经进货、医馆的洁净料。它是**夜里走正统仪轨的门票**。

赶工、脏料、糊弄，会把洁净磨薄。洁净仪轨（铺务里一次清扫式的处理）在叙事上是「把铺子擦回能见人」——也可用于洗掉更重的「不对劲」标记（见 §6；清除条件 **【暂定/可改】**）。

### 4.5 履约现场：规矩 / 道具 / 人情

夜生意的生存辅循环长在这里：短场景，把「局面」压下去，完成送达 / 封门 / 安座等主目标。玩家支付的是：

- **规矩**：你会不会走、走得正不正；
- **道具**：白天备下的符与纸货（脏料也能用，但邪门）；
- **人情**：叫谁来顶、谁肯作证或圆场。

可以压下（留把柄、付更大人情）、可以跑路（夜口碑伤、目击者具名后果）。多数夜单可算计、可冷幽默收束；**顶格夜**【示例】每隔若干镇日至多一回——选项更少、文案更静、失败伤经营更重。

**【暂定/可改】** 履约主流程用回合制还是一次性三槽——模块 GDD 现默认回合制，**未拍板**，世界叙述两端都说得通：要么是「一步错一步」的现场周旋，要么是「三样东西一次摆上台面」的交法。

## 5. 纸火 / 纸扎行业在宇宙里的位置

### 5.1 这一行是干什么的

纸扎铺夹在阳间仪式服务与阴事中介之间：

- **阳面**：把「该有个说法」的东西做出来——纸人纸马、符、净宅材料——让活人安心、让场面过得去。
- **阴面**：让「那侧」也认账。同一件货，可能要满足两套条件；有的客户白天是人，夜里是事主或中间人。

行业在宇宙里的位置：**不是除魔公司，是小镇刚需的灰色基础设施**。庙拆了、立案不便、短视频又爱乱拍——纸扎行与香火行就成了「旧规矩的柜台化」。你爷爷夜里也接；老人一句点破，却白天装瞎。

气质借纸嫁衣的纸人纸马、婚葬与乡土空间情绪；主菜仍是经营，不做成纯章节解谜 AVG。

### 5.2 纸马童为什么「说得通」

铺里坐着一个常被客人当成纸人装饰的「童」：白天几乎不主动说话，偶尔递错东西（冷幽默）；夜里接待、带路、引荐夜单。规则上通关前定位是**引荐 + 带路**，不做战斗宠。

**【暂定/可改】终局解释（模块 GDD 现默认「旧愿」主线）**：

| 解释枝 | 世界说法 | 味道 |
| --- | --- | --- |
| **旧愿**（现默认占位） | 长辈或某桩未了之事托在铺里；你接手祖业＝接手愿 | 经营债与人情债合一 |
| 非人看门 | 铺需要一个「不是伙计」的守门者 | 身份持续疑问拉满 |
| 长辈错身 | 某种错位留守 | 更私密、更凉 |

未拍板前：文案保持模糊回绝，不提前剧透。三种都能解释「为何铺子夜账能开、为何外乡也能被引上路」。

### 5.3 香火店等同行

对门香火店（若启用）：白天抢单压价、说你外乡不懂；夜里可能甩锅或请你共背。叙事上宜**利益动物邻居**，不是可灭门反派。脏料渠道、竞争压力由此来。

**【暂定/可改】** 是否进常驻镇脸、是否影响进货加权——模块 GDD 现默认进常驻；角色草案仍列为可选。

林医生、柳裁缝、陈婶等：分别卡在洁净 / 规矩知识 / 阳间中介上——行业生态靠「镇脸」转，不靠抽象公会等级。

### 5.4 信物在世界里是什么

信物是「这镇认你办成过难事」留下的物件：旧账铜扣、顶针、空烟盒、纸马蹄铁……叙事优先于数值。效果宜是省一次心、多一句提示、轻一点惩罚，而不是装备膨胀。

**【暂定/可改】** 一周目作打满彩蛋 / 轻量成长、同时生效上限【示例】3、不挡封门、新周目默认不继承——均为未拍板默认，见 §8。

## 6. 口碑、被盯、坏结局：世界叙事上的含义

### 6.1 两套口碑，两套社会

| | 镇民信任（阳） | 夜口碑（阴） |
| --- | --- | --- |
| 世界含义 | 你还是不是「正经铺」；陈婶还介绍不介绍 | 老人认不认你、夜里还有没有稳妥单 |
| 涨的时候 | 阳交货漂亮、公开圆场 | 诡履约成功、守密、柳点头 |
| 跌的时候 | 夜事外溢、短视频传闻、日间抽查 | 拒被盯、泄夜密、跑路 |
| 交叉 | 揭穿支书夜事：白天镇民可能爽，夜里你少一个客户 | 夜失败常两边一起难看 |

玩家应感到：**口碑是人在说话**，不是一个合成好感。阿杰发视频、支书来查、陈婶不再介绍——比「口碑 -10」疼。

### 6.2 「被盯」是什么

有的夜单不理它也会记你：阴气微抬、把柄留几天、被盯权重上升。叙事上是「那侧或中间人已经看见你这间铺」。可以花钱洗把柄【示例】——世界说法像疏通或补一刀香火，不是无敌护盾。

**【暂定/可改】** 把柄持续天数、每周可洗次数——模块 GDD 现有默认，未拍板。

### 6.3 「不对劲」与坏结局

「不对劲」是比普通失败更沉的叙事标记：顶格砸过后，或阴气炸街挂过后，铺子像被人记住了。清除需要一段时间稳住 + 一次洁净仪轨（**【暂定/可改】** 具体天数与条件）。

坏结局在世界里不是 Game Over 跳脸，是**短过场**：易主、离开小镇、账本合上。可读档回上一日日初——小品允许重来，不鼓励同一履约现场反复重 roll。

门槛叙事化说法【示例】：阴气顶满；阳阴口碑双尽且破产；顶格失败时身上还挂着「不对劲」。普通失败白天能补（低价阳单、送礼、精工、稳妥小夜单）——**经营感靠「还能补」托住**，高压靠顶格与炸街偶发。

**【暂定/可改】** 「不对劲」获得/清除、Ty=0 是否假死一晚再并入破产检、坏结局是否过狠。

## 7. 与玩法模块的咬合摘要 + 【冲突待拍板】

### 7.1 咬合摘要（设定 → 玩法，不重复规则全文）

| 设定块 | 咬合模块 | 玩家应感到 |
| --- | --- | --- |
| 外乡接手、两本账 | 壳层账本日/夜页；教学翻夜页 | 你以为加班做纸人，其实夜账开了 |
| 阳间日常 / 阴事私下 | 03 阳单；04 夜单与履约 | 日稳夜险；两边互相拖累或救命 |
| 日夜错位镇脸 | 07 角色加权、揭穿/保密 | 单都绑得住人 |
| 规矩 / 禁忌 / 洁净 | 05；打听 09 | 不知更致命；脏铺只剩歪办 |
| 阴气与紧张态 | 02 资源；06 失败 | 街谈发虚，不是血条归零 |
| 人情具名 | 07 人情卡 | 叫谁来比点数好看 |
| 双口碑与具名后果 | 06 | 谁在议论你 |
