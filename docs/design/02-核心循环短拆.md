# 《纸火》（暂名）核心循环短拆（可改稿）

| 项 | 内容 |
| --- | --- |
| 用途 | 立项后玩法对齐；非完整系统方案 |
| 平台/体量 | PC 小品；主线约 8–15h |
| 已拍板 | 经营为主、生存为辅；冷幽默 + 偶发高压；主角 = **外乡接手祖业** |
| **日夜口径（2026-11-05 修订）** | **白天接阳间生意；晚上接诡异生意** |
| 尺度 | 偏发忌 / 错身 / 纸人自行；少血腥 |
| 概念来源 | 塞莎特《概念一页纸》；循环口径按 Charlie 修订 |

---

## 1. 一句话目标与成功标准

**目标**：你开的是一间「白天正经、夜里不讲」的纸扎铺——太阳底下做红白事与镇民订单，天黑后另开一本账接阴事；两边的材料、口碑和人情会互相拖累或互相救命。

**成功标准（玩 1～2 小时应感到）**

1. 日夜是两套生意，不是「白天赚钱、夜里只挨打」。
2. 阳间单稳、反馈快；阴间单报酬高、规矩狠、偶发高压。
3. 白天备的料、人情、洁净度，夜里接诡异单时真的用得上；夜里搞砸会砸次日阳间客源。
4. 冷幽默多在阳间柜台与镇民圆场；高压多在阴间交货现场。
5. **日夜出现的人好认、好记**：同一张脸可能「日一套说法、夜另一套事」；角色特征是最大故事亮点（详见《纸火-日夜角色特征草案》）。

---

## 2. 玩家是谁（外乡接手祖业）

- 外乡回来接手长辈铺子；账本里本来就有「夜账」一栏，镇里老人假装不知道。
- **教程**：先教白天阳间接单；第一个夜里用「账本翻到夜页」打开诡异生意（可冷幽默：你以为是加班做纸人）。
- **压力**：白天要维持「正常铺面」人设；夜里单子不能声张，却总被老人一句「你爷爷夜里也接」点破。
- 开场短过场即可，不做长身世 AVG。

---

## 2.1 故事亮点：日夜的人（摘要）

- 经营单不只是模板，**每张重要单都绑一个说得清的人**（要什么、怕什么、日夜是否同一人）。
- 【建议】常驻 6～8 张「镇脸」+ 若干一次性客；玩家靠口头禅、物件、站位认出他们，而不是靠好感度数。
- 日夜错位是核心趣味：白天催你别搞封建的人，夜里可能塞红包；夜里托事的人，白天在居委会把你当正常人寒暄。
- 完整钩子、功能、禁忌关系见附件角色草案；本短拆只定「人驱动订单与夜履约」。

---

## 3. 日夜双经营（主循环）+ 生存压力（辅）

### 3.1 总图（修订后）

```
白天 · 阳间生意（稳、公开）         夜里 · 诡异生意（险、私下）
镇民红白事 / 符 / 净宅 / 寻物等      阴事中介：送行、安魂、两套账、纸人条件…
→ 接/拒/议价（少禁忌或轻禁忌）      → 接/拒/议价（重禁忌表）
→ 备料、工艺、雇人、交期             → 用白天库存与人情；或连夜赶阴面工艺
→ 交货、收钱、涨「镇民信任」         → 现场履约：仪轨/道具/人情三选组合
→ 进货、修铺、还人情、为夜里备料     → 成败改阴气、夜口碑、次日阳间客流
        ↑_______________________________|
         夜单搞砸 → 伙计怕、白天客少、铺面被议论
         白日做稳 → 夜里更敢接、料更全、人情更够
```

**经营为主**：日夜都是「接单→履约→结算」；差别在客户、规则书强度、履约场面。  
**生存为辅**：主要挂在**夜里履约过程**（短事件式交付），不是单独再开一个「纯挨冻挨吓」时段。

**会话节奏**【建议】：一个镇日 = 白天阳间档（约 10～18 分钟）+ 夜里诡异档（约 5～12 分钟，含接单与履约）。白天多存档点；夜里履约段不鼓励同一现场反复读档重roll。

### 3.2 白天：阳间生意

| 步骤 | 玩家在做什么 | 反馈 | 与夜里的关系 |
| --- | --- | --- | --- |
| 接单 | 红白纸扎、安神符、搬家净宅、寻物、日常送行（阳面） | 钱、交期、镇民信任 | 部分材料/成品可转夜里用；极少数单「留到夜里再谈」入口 |
| 备料工艺 | 正料/替代、精工/赶工、是否叫帮工 | 成本、洁净度、工期 | **洁净料与人情是夜单门票** |
| 交货 | 柜台或上门，公开、可冷幽默 | 口碑（镇民信任为主） | 做砸了夜里仍可营业，但料与人情变紧 |
| 铺务 | 进货、修铺、稳住伙计、送礼 | 产能、抗议论能力 | 伙计「怕夜里」是关键资源：怕到一定程度会拒夜班 |

**阳间禁忌**：有，但轻——多为交期、彩头、能不能拍照；犯规主要扣钱与信任，不轻易拉满阴气。

### 3.3 夜里：诡异生意

| 步骤 | 玩家在做什么 | 反馈 | 生存辅循环在哪 |
| --- | --- | --- | --- |
| 开夜账 | 看今夜上门/托梦/纸条单；接/拒/加价 | 报酬高、关系网（老人/「那侧」） | 拒单也有代价（被盯、把柄） |
| 备阴面 | 检查禁忌表；缺料则用白天库存或冒险替代 | 选项多寡 | 替代料 = 履约时风险标签 |
| 履约现场 | 短场景：送客、封门、对簿、安纸人、错身交涉等 | 成功赏钱/信物；失败砸资产 | **此处才是高压与化解**（规矩/道具/人情） |
| 收摊 | 阴气、夜口碑、是否惊动镇民 | 写入次日阳间：客流、议论、伙计胆量 | 偶发「顶格夜」一次履约失败伤得很重 |

**夜单类型（示例模板）**：阴面送行、安魂/安神（真假客）、两套账补做、纸人自行善后、寻「不该寻」之物、庙拆后的无名单。  
**夜口碑**：与阳间信任分开；老人认可、同行忌惮可主要在夜账涨。

### 3.4 偶发高压怎么挂在「夜生意」上

- 多数夜单：可算计、可冷幽默收束（「科学说法」圆场、纸人自己坐下等）。
- **顶格夜单**【建议】每 3～5 镇日至多 1 单：选项更少、文案更静、失败重伤经营或「你自己不对劲」。
- 玩家可以当晚少接、只做一单阳转阴的尾巴——**经营选择本身就是降压手段**，符合「经营为主」。

## 4. 资源（仍是四类，日夜共用池）

| 资源 | 白天（阳） | 夜里（诡） | 缺了怎样 |
| --- | --- | --- | --- |
| 钱 | 主收入 | 高报酬但不稳定 | 进不起料、不敢拒烂单 |
| 材料/洁净度 | 公开进货、精工累积 | 消耗更快；脏料锁定危险选项 | 夜单只能歪办，易顶格 |
| 人情 | 镇民送礼、帮忙 | 请人护法、顶缸、作证 | 履约只剩自己硬扛 |
| 阴气（越低越好） | 阳间犯规轻抬 | 夜单主来源；守规矩可降 | 夜单变密变凶，白天客也虚 |

**【建议】UI**：一本账两页（日页/夜页）+ 黄历宜忌；少用大 RPG 面板。

---

## 5. 诡异感进规则

1. **两本生意两套规则书**：阳页轻忌、夜页重忌；不是同一张单拖到夜里挨罚。
2. **两套账**仍存在，但归类为**夜单或「日接夜交」**：白天可收订金，夜里才履阴面。
3. **现代乡土**：白天青年顾客催你「别搞封建」；夜里同一条街又有人塞红包——冷幽默来自你两边都点头。
4. 气质：规矩与信息差（鬼吹灯）挂在夜履约；纸扎婚葬情绪（纸嫁衣）挂在单种与现场，主菜仍是经营。

---

## 6. 失败与补救

- **阳间失败**：扣钱与信任；很少直接炸夜账。
- **夜履约失败**：伙计拒夜班、次日阳客减少、铺面被贴议论；顶格才触及坏结局。
- **补救**：白天做稳单、送礼、补洁净料、还人情——再用夜里接稳妥小单回血。
- **不做**：大地图追逃、硬砍怪、联机、赛季。

**开放点**【建议】占位

| 点 | 【建议】 | 待你拍 |
| --- | --- | --- |
| 日单能否「转夜」 | 允许少数：收订金，夜页履约 | 比例多少 |
| 夜班伙计 | 开局可独自夜班；中期才有敢上夜的伙计 | 是否要专属夜伙计 |
| 夜单拒绝 | 可拒，抬「被盯」而不是强制接 | 拒的惩罚曲线 |
| 一周一周目 | 夜账更滑、忌更严 | 通关后再做 |
