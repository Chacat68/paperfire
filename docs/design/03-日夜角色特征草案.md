# 《纸火》日夜角色特征草案（可改稿）

| 项 | 内容 |
| --- | --- |
| 用途 | 服务核心循环：人是最大故事亮点；订单与夜履约由「镇脸」驱动 |
| 已拍板口径 | 白天阳间生意 / 晚上诡异生意；外乡接手；冷幽默 + 偶发高压 |
| 非目标 | 不做完整人物志、分支恋爱或全员立绘规格书 |

---

## 1. 设计原则

1. **一张脸一个钩子**：外貌/口头禅/随身物三选二即可认出，不靠姓名字幕。
2. **日夜可以错位**：同一人两套社会面具；或「日是人、夜是事主/中间人」。错位本身出冷幽默与高压。
3. **功能绑角色**：谁带来阳单、谁开门夜账、谁收人情、谁在顶格夜出现——避免NPC只念旁白。
4. **外乡视角**：角色用「你爷爷从前…」「你们城里人…」推信息，少用说明书对白。
5. **尺度**：发忌、错身、纸人自行；角色惊吓靠态度与规矩，不靠血腥人设。

---

## 2. 常驻「镇脸」提案（6～8）

> 名字可改；先认功能与日夜差。★ = 建议优先实装。

### ★ 陈婶（阳柜台流量）

| | |
| --- | --- |
| 钩子 | 永远提着保温袋；开口先问「你吃了没」再谈事 |
| 白天 | 红白事打听、介绍邻居单；用闲话给你涨镇民信任 |
| 夜里 | **很少现身**；若现身多半是托你「别跟我媳妇说」的小阴事（冷幽默） |
| 玩法 | 阳单中介；人情缓冲；误会发生器 |

### ★ 吴支书（现代说法）

| | |
| --- | --- |
| 钩子 | 袖标/工作证；说话像念通知，却总在包里摸烟 |
| 白天 | 催你合规、别搞封建；可给「净宅」「宣传用符」类阳单 |
| 夜里 | **同一人换便装塞红包**，要你「按老规矩」处理不敢立案的事 |
| 玩法 | 日夜错位样板；选帮他圆场还是揭穿影响阳口碑 vs 夜报酬 |

### ★ 老裁缝柳（规矩库）

| | |
| --- | --- |
| 钩子 | 手指戳人；只信黄历与你爷爷的旧账本 |
| 白天 | 挑剔你工艺；教轻忌；老人认可主要来源 |
| 夜里 | 夜账「顾问」：解锁仪轨选项，但要你欠人情或帮他一个旧愿 |
| 玩法 | 知识商人；高压夜几乎必能打电话给他（代价大） |

### ★ 阿杰（短视频青年）

| | |
| --- | --- |
| 钩子 | 手机补光灯；张口「我拍下来发一下」 |
| 白天 | 要改装纸扎「好看」、催快工；科学说法代言 |
| 夜里 | 可能成**事主**：拍到不该拍的，或求你删图/安神 |
| 玩法 | 轻禁忌冲突（拍照）；教程期冷幽默；后期可变顶格线引线 |

### ★ 纸马童（铺里「不是伙计」）

| | |
| --- | --- |
| 钩子 | 坐在纸马旁；客人有时当他是纸人装饰 |
| 白天 | 几乎不主动说话；偶尔帮你递错东西（冷幽默） |
| 夜里 | **夜账接待/带路**；真正身份开放（旧愿、长辈留下的看门者、错身） |
| 玩法 | 夜生意入口的人格化；不要做成战斗宠 |

### 医馆林医生（洁净与科学）

| | |
| --- | --- |
| 钩子 | 消毒水味；把符当「安慰剂」却收得认真 |
| 白天 | 安神符、净宅联名阳单；卖洁净材料 |
| 夜里 | 拒诊的「病人」被转到你夜账；他日间装作不认识 |
| 玩法 | 材料商人 + 日夜装瞎 |

### 对门香火店（可选·同行忌惮）

| | |
| --- | --- |
| 钩子 | 笑脸报价；夜里焚香特别勤 |
| 白天 | 抢单、压价、说你外乡不懂 |
| 夜里 | 可能甩锅单、或请你「共背」一单 |
| 玩法 | 竞争压力；慎做成纯反派，宜利益动物 |

### 已故长辈「只留声音」（可选·教程锚）

| | |
| --- | --- |
| 钩子 | 账本批注、旧录音、纸人背后字迹 |
| 白天 | 工艺提示 |
| 夜里 | 禁忌提示；从不正面出影（尺度友好） |
| 玩法 | 外乡教程；不占常驻对话位 |

## 3. 日夜错位组合（故事发动机）

| 组合 | 白天玩家看到 | 夜里玩家看到 | 设计意图 |
| --- | --- | --- | --- |
| 吴支书线 | 反封建通知 | 便装求老规矩 | 最大错位喜剧/凉意 |
| 阿杰线 | 要拍摄引流 | 求删图/安魂 | 都市传说进单 |
| 陈婶线 | 热心红白事 | 隐瞒家事小阴单 | 温情冷幽默 |
| 林医生线 | 科学口吻卖符 | 推来拒诊怪客 | 两套账社会版 |
| 纸马童线 | 像摆设 | 像同事 | 「铺子里谁是活人」持续疑问 |

**【建议】主线亮点排期**：前 2 小时打透「吴支书错位」+「纸马童是谁」；中期再展开阿杰/林医生；顶格夜优先消耗柳裁缝人情。

---

## 4. 一次性客 vs 常驻

- **一次性**：脸谱化即可（急婚、赶丧、拆迁户），服务订单模板多样性。
- **常驻**：必须重复出现 ≥3 次，且至少 1 次日夜状态变化。
- 夜履约现场的「事主」优先从常驻池变形，少用全新脸，强化「这镇就这些人」。

---

## 5. 和循环的接口（给关卡/文案）

1. 阳单生成：加权常驻钩子（陈婶介绍、支书任务、阿杰定制）。
2. 夜单生成：加权同一人的夜面具或纸马童引荐。
3. 人情卡：具名（「叫柳裁缝来」）比抽象点数更有故事。
4. 失败后果：具名化（阿杰发视频、支书来查、陈婶不再介绍）比「口碑 -10」更痛。

---

## 6. 开放点（待你拍）

1. 纸马童最终解释：旧愿 / 非人看门 / 长辈错身——三选一或到结局才亮。
2. 吴支书是否可成长为「白日继续装、夜里成固定夜客户」。
3. 是否需要「女主角级」单线（当前草案刻意用群像，避免恋爱导向）。
4. 对门香火店要不要进常驻：要则加竞争经济，不要则减写。
