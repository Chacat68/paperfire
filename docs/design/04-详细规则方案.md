## 0. 时间与会话单位

| 单位 | 定义 | 【示例】 |
| --- | --- | --- |
| 镇日 | 完整一天：日档 + 夜档 | 主线约 12–20 个镇日可通（对应 8–15h） |
| 日档 | 阳间营业时段 | 有效操作 10–18 min |
| 夜档 | 诡异营业 + 履约 | 5–12 min |
| 行动点 AP（可选） | 日档内限制「接谈/备料/铺务」次数，防刷 | 日档【示例】6 AP；接谈1、备料1、交货0（合并在接谈链）、铺务1、打听1 |

**【建议】**：若嫌 AP 脏，可只用「墙上挂钟」三段（午前/午后/傍晚）每段 1～2 次重大决策。

**存档**【建议】：日档任意柜台可存；夜履约进入现场后至结算前，读档回「夜账接单界面」，不回滚到现场内上一步（降低重roll）。

## 1. 资源与日夜结算

### 1.1 资源一览

| 资源 | 显示名【建议】 | 范围【示例】 | 日档主用途 | 夜档主用途 |
| --- | --- | --- | --- | --- |
| Money `M` | 现金 | 0～9999；开局 80 | 进货、议价空间 | 少直接花；可雇临时护法 |
| Stock `S` | 材料（普通） | 0～99；开局 12 | 阳面工艺 | 可挪作阴面赶工（掉洁净） |
| Clean `C` | 洁净度（料/铺） | 0～20；开局 8 | 精工产出 | 解锁「正统仪轨」档选项 |
| Favor `F` | 人情（抽象池） | 0～15；开局 2 | 送礼、请人 | 履约消耗具名人情卡也扣池 |
| Haunt `H` | 阴气（越低越好） | 0～20；开局 3 | 阳犯规轻抬 | 夜单主涨跌 |
| Trust_Yang `Ty` | 镇民信任 | 0～20；开局 4 | 阳单流量 | 夜砸盘会跌 |
| Trust_Yin `Tn` | 夜口碑 | 0～20；开局 1 | — | 诡单流量、老人认可 |
| Nerve `N` | 伙计胆量 | 0～10；开局 5（若暂无伙计则藏） | — | ≤2 拒夜班 |

**呈现**【建议】：现金与材料见账本；洁净/阴气多用环境与街谈；信任拆日页/夜页两行，不合成一个「好感」。

### 1.2 日末 → 夜初 结算

每日「落锁营业」时自动：

1. `H := H + 日档犯规累计`（见 §3）  
2. 若当日有「日接夜交」订金单，推入夜账待办，不另加 `H`（已在接单时结算过风险标签）  
3. 材料 `S`、`C` 原样带入夜档（共用库存）  
4. 生成夜单池（见 §5、§2.3）

### 1.3 夜末 → 次日日初 结算

夜档收摊时：

| 结果类型 | 【示例】写回 |
| --- | --- |
| 夜履约成功（普通） | `M+`报酬；`H-1`（至少到0）；`Tn+1` |
| 夜履约成功（顶格） | 同上，且 `Tn+2`；可能给信物（永久小加成） |
| 夜履约「压下」 | `M` 半报酬；`H` 不变或 +1；挂「把柄」标记 1～3 日 |
| 夜履约失败（普通） | `M` 无或少；`H+2`；`Ty-1`；`N-2`；触发 1 个具名议论 |
| 夜履约失败（顶格） | `H+4`；`Ty-3`；`N-4`；可能贴条/封门 1 日（日档强制少单） |
| 拒接所有夜单 | `H+0`；`Tn` 不涨；若池中有「被盯」单未处理，`H+1` |

**【示例】报酬带**：普通夜单 40～90；顶格 100～160；阳单 15～45。

### 1.4 资源紧张的体验阈值（给手感，非公式宗教）

| 状态 | 条件【示例】 | 玩家感到 |
| --- | --- | --- |
| 紧巴 | `M<30` 或 `S<5` | 只能接短交期小单 |
| 脏铺 | `C<4` | 夜仪轨只剩「歪办」 |
| 没人帮 | `F=0` 且无可用具名卡 | 顶格夜极难 |
| 镇虚 | `H≥12` | 夜单变凶；日客台词发虚 |
| 炸街 | `H≥18` | 强制遭遇顶格候选；接近坏结局检定 |

## 2. 订单规则

### 2.1 订单公共字段

| 字段 | 说明 |
| --- | --- |
| `id` / `face` | 模板 ID；绑定角色脸（常驻或一次性） |
| `realm` | `yang` \| `yin` \| `bridge`（日接夜交） |
| `pay_base` | 基础报酬【示例】 |
| `due` | 交期：当日傍晚 / 次日 / 夜当场 |
| `need_S` / `need_C` | 材料与洁净需求 |
| `taboos[]` | 禁忌条目（见 §3） |
| `risk` | 0～3；影响 `H` 与夜牌权重 |
| `tags` | 红白/符/净宅/寻物/送行/安魂/两套账/纸人… |

### 2.2 阳间单（`yang`）

**流程**：刷新（每午前）→ 接/拒/议价 → 备料 → 交货 → 结算。

| 动作 | 规则 | 【示例】 |
| --- | --- | --- |
| 刷新数量 | 受 `Ty`、角色加权 | `Ty` 0–6：2 单；7–13：3；14+：4 |
| 拒单 | 一般无惩罚；绑定陈婶/支书的单拒有轻罚 | `Ty-1` 或下次刷新少 1 单 |
| 议价 | 一次；成功看 `Ty` 与角色 | +10%～20% 报酬或换长交期 |
| 赶工 | `-1C` 或 `+1` 轻忌犯规计数 | 省 1 日交期 |
| 精工 | `-额外S`，`+1C`（上限内） | 交货 `Ty` 额外 +1 |
| 交货成功 | | `M+pay`；`Ty+1`（首次帮某脸 +2） |
| 交货失败/严重犯规 | | `M` 无；`Ty-2`；轻忌累计入日末 |

**阳间轻忌**【示例】：不能在客人面前讲价死气、不能让阿杰开闪光灯、属相日不交白事纸扎等——犯规记 `day_offense +=1`，日末 `H += min(2, day_offense)`。

### 2.3 诡异单（`yin`）

**流程**：夜初刷新 → 接/拒/加价 →（可选连夜备阴面）→ **履约现场** → 结算。

| 动作 | 规则 | 【示例】 |
| --- | --- | --- |
| 刷新数量 | 受 `Tn`、`H`、角色 | 基础 1；`Tn≥5` 可 2；`H≥12` 强制至少 1 张「被盯」 |
| 顶格标记 | 每 3～5 镇日至多 1 | 见 §3.4 |
| 拒单 | 可拒；池中「被盯」拒则 | `H+1`，并留把柄 |
| 加价 | 夜可更狠 | +20%～40%，但 `risk+1` |
| 接单瞬间 | 预扣或锁定料 | 锁定 `need_S`；不足则自动标「替代料」 |

### 2.4 日接夜交（`bridge`）

- 日档收订金【示例】30%～50% `pay_base`。  
- 夜档必须履阴面；未履约视同夜失败（普通）。  
- **用途**：吴支书白天「净宅宣传单」夜里变真阴事——错位叙事接口。

### 2.5 样例单（各 2 张，绑角色）

**阳 · 陈婶介绍的白事纸扎**  
`pay_base=28`；`due=次日`；`need_S=4`；`need_C=0`；轻忌：交货勿笑场；成功 `Ty+2`（陈婶线）。

**阳 · 吴支书合规净宅**  
`pay_base=35`；`need_S=3`；`need_C=1`；标签 bridge 可选；若勾 bridge，夜履约另算。

**诡 · 吴支书便装安魂**  
`pay_base=70`；`risk=2`；`need_S=3`；`need_C=3`；重忌：不可录音、不可第三人在场；履约三件套检定。

**诡 · 阿杰删图安神（可顶格候选）**  
`pay_base=90`；`risk=3`；禁忌：已传播的图要「收回说法」；失败具名：短视频议论 `Ty-3`。

## 3. 禁忌与夜履约

### 3.1 禁忌表怎么生效

每条禁忌有：

| 字段 | 说明 |
| --- | --- |
| `code` | 如 `no_photo` / `month_block` / `no_third` |
| `when` | 接单检 / 备料检 / 履约检 |
| `break_cost` | 犯规代价：`H+`、锁选项、改结局支 |

**检定顺序**：接单时显示「可知禁忌」（外乡靠账本/柳裁缝打听解锁）；隐藏禁忌在履约中揭示（信息差）。

打听【示例】：日档花 1 AP + `F` 或求柳：揭示某单 1 条隐藏忌。

### 3.2 夜履约：三件套

进入现场后，玩家看到 **局面值 `Threat`【示例】1～5**（由 `risk`、`H`、是否顶格、是否替代料 合成）。

每回合（或一次性三选槽）可支付：

| 手段 | 支付 | 效果【示例】 |
| --- | --- | --- |
| 规矩 | 需已解锁对应仪轨；可耗 `C` | `Threat-2`；错选则 `Threat+1` 且 `H+1` |
| 道具 | 耗预做符/纸扎成品/`S` | `Threat-1`；脏料版 `Threat-1` 但 `H+1` |
| 人情 | 耗 `F` 或具名卡（柳/陈婶等） | `Threat-2`；具名卡带特殊解（支书圆场等） |

**胜利**：`Threat≤0` 前完成「主目标条」（送达/封门/安座等）。  
**压下**：付双倍人情或留把柄，强制 `Threat=0` 但走压下结算。  
**失败**：`Threat` 仍高且选项耗尽，或选「跑路」。

**【示例】Threat 初值** = `risk + clamp(H/6,0,2) + (替代料?1:0) + (顶格?2:0)`。

### 3.3 跑路

允许。结算：按普通失败，另 `Tn-1`；若现场有目击者脸，触发该脸具名后果。

### 3.4 顶格夜

| 规则 | 【示例】 |
| --- | --- |
| 频率 | 每 3～5 镇日 ≤1；可用「节气/庙会」强制排期 |
| 选项 | 少 1 个通用手段；错规矩惩罚加倍 |
| 失败 | 走顶格失败表（§1.3）；接近坏结局 |
| 文案 | 更静；冷幽默收束默认关闭 |

## 4. 失败与口碑

### 4.1 双口碑

| | `Ty` 镇民信任 | `Tn` 夜口碑 |
| --- | --- | --- |
| 涨 | 阳交货、陈婶线、公开圆场 | 诡履约成功、柳认可、守密 |
| 跌 | 夜失败外溢、阿杰传播、支书日间查你 | 拒被盯单、泄夜密、跑路 |
| 影响 | 阳单数量、议价、封门概率 | 诡单数量、仪轨解锁速度 |

**交叉**：夜失败常 `Ty` 与 `Tn` 双跌；日间揭穿吴支书夜事：`Ty+?`（镇民爽）但 `Tn` 大跌、失客户。

### 4.2 具名后果表（优先于纯数字）

| 触发 | 具名后果【示例】 |
| --- | --- |
| 夜失败 × 阿杰相关 | 镇群传闻；次日阳刷新 -1 单 |
| 夜失败 × 吴支书 | 日间「抽查合规」；强制接 1 张低价阳单 |
| 夜失败 × 伙计在场 | `N-3`；台词拒夜 |
| `N≤2` | 不可带伙计履约；产能 -1 |
| `Ty≤2` | 陈婶暂停介绍 |
| `H≥18` 连续 2 夜 | 进入坏结局检定 |

### 4.3 坏结局门槛【示例】

任一条：

1. `H≥20`  
2. `Ty=0` 且 `Tn=0` 且现金破产（`M=0` 且 `S=0`）  
3. 顶格失败且已有「不对劲」标记  

→ 短坏结局（易主/离开小镇）；读档回上一日日初。

### 4.4 普通失败的补救（经营感）

次日可用：低价阳单×2 回 `M`；送礼回 `F`；精工回 `C`；主动接 1 张低 risk 夜单回 `Tn`——**明确告诉玩家「白天还能补」**。

## 5. 角色接口规则

### 5.1 出单加权

每日刷新时，对每个常驻脸算权重再抽样：

| 脸 | 阳单权重因子【示例】 | 诡单权重因子【示例】 |
| --- | --- | --- |
| 陈婶 | 高（+3）；`Ty` 低时更高 | 极低；偶发小阴事 |
| 吴支书 | 中；剧情日强制 | 中高；错位线任务日强制 1 |
| 柳裁缝 | 低（多对话少单） | 顾问事件而非单 |
| 阿杰 | 中；要拍摄类 | 中；删图/安神 |
| 林医生 | 中；符与洁净 | 中；拒诊转介 |
| 纸马童 | 无阳单 | 引荐：全池 +1 张「童引」单 |
| 一次性脸 | 补足数量 | 补足数量 |

**重复出现规则**：常驻脸主线相关至少每 2～3 镇日露 1 次（日或夜）。

### 5.2 具名人情卡

| 卡 | 获得【示例】 | 履约效果 |
| --- | --- | --- |
| 叫柳裁缝 | 欠柳 1 个旧愿或 `F-2` | `Threat-3`；可揭示 1 隐忌 |
| 陈婶圆场 | `F-1` 且陈婶线进度 | 仅非顶格；改写目击者议论 |
| 支书盖章 | 帮吴完成 1 次错位单 | 日间免抽查 1 次；夜用则 `Ty-1`（穿帮风险） |
| 纸马童带路 | 童信任（剧情） | 跳过 1 个迷路/错身检 |

抽象 `F` 可在无卡时花 2 点当「临时外人」：`Threat-1` only。

### 5.3 揭穿 / 保密（吴支书样板）

| 玩家选择 | 【示例】结算 |
| --- | --- |
| 夜里接单并守密 | `M+`；`Tn+1`；标记 `wu_secret` |
| 日间揭穿 | `Ty+2`；`Tn-3`；吴退出夜客户池 |
| 表面守密日间拿捏 | 可勒索 1 次桥单；失败则双口碑跌 |

### 5.4 纸马童规则占位

- 日档：不占刷新名额；可触发 1 句冷幽默。  
- 夜档：若 `Tn≥3` 或剧情旗，提供「童引」单。  
- **最终身份**：开放点；规则上在通关前只作「引荐+带路」，不做战斗宠。

## 6. 开局【示例】与前 3 镇日脚本目标

**开局**：`M80 S12 C8 F2 H3 Ty4 Tn1 N5`。

| 镇日 | 目标（设计验证） |
| --- | --- |
| D1 | 只阳单；认识陈婶/阿杰；落锁翻夜页教程（可接 1 张 risk0～1） |
| D2 | 吴支书日间阳单；夜里便装错位（必遇一次） |
| D3 | 可学打听；柳给第一条仪轨；故意给一次「差一点失败」的普通夜单教补救 |

## 7. 已拍板 / 开放点 / 数值免责

**已拍板**：五块规则结构；日夜两套生意；人驱动；冷幽默+偶发高压；外乡。  

**开放点**：AP vs 时段制；纸马童终局；一周目；对门香火店是否入加权表。  

**数值**：文中所有数为【示例】，平衡前只保证「相对大小」：夜报酬 > 阳报酬；顶格威胁 > 普通；补救成本 < 顶格失败创伤。
