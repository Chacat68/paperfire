## 阅读入口

1. 先读主文 **第1～3章**：设计边界、世界观（第2章）、日夜主路径与结算。  
2. 需要展开世界气质 / 诡异规则草稿时，可并行读 [01-背景设定-世界观与诡异规则.md](./01-背景设定-世界观与诡异规则.md)（可改稿）；**冲突以第2章为准**。  
3. 再按需读 **第4章** 各系统块（时间、资源、白天的单、夜履约、禁忌、失败、角色、进货、打听、信物、教学/一周目节奏 D1–D15）。  
4. 未拍板项统一见主文 **附录 B**；七条系统默认见 **第2.6节**（均为【暂定】【待拍板】）。
