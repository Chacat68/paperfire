## 1. 模块目标与玩家感受

- 打开游戏就像走进一间纸扎铺：账本、黄历、柜台、街巷入口都在手边，而不是 RPG 大面板。
- 日页明亮、可冷幽默；夜页更静、字距疏一点——玩家靠壳层气质就知道「现在哪本账」。
- 任何灰按钮都能问「为什么不能点」；危险操作有二次确认；落锁/收摊有短仪式，形成日夜呼吸。

## 2. 规则全文

### 2.1 会话壳状态机（顶层）

| 状态 | 说明 | 可进 |
| --- | --- | --- |
| `BOOT` | 启动 Logo / 版权 | → 主菜单 |
| `MAIN_MENU` | 主菜单 | → 新局 / 读档 / 设置 / 退出 |
| `DAY_SHOP` | 日档经营（柜台默认） | 订单/账本/街巷/伙计/菜单；落锁 |
| `DAY_TO_NIGHT` | 落锁仪式 + 日末结算演出 | → 夜接单 |
| `NIGHT_BOARD` | 夜账接单界面 | 接拒/加价；进履约；收摊（待办清完） |
| `NIGHT_FULFILL` | 履约现场 | **禁存**；胜/败/压下/跑路 → 回夜接单或结算 |
| `NIGHT_TO_DAY` | 收摊仪式 + 夜末结算 | → 次日日初 或 坏结局 |
| `BAD_END` | 短坏结局过场 | → 读档上一日日初 |
| `PAUSE` | 暂停/系统菜单（叠在合法壳上） | 设置、存读档（受禁存边界） |

### 2.2 常驻 HUD（日/夜共用骨架，皮肤不同）

| 区 | 日档显示 | 夜档显示 | 备注 |
| --- | --- | --- | --- |
| 左上 · 日夜态 | 「日 · {period}」+ 挂钟氛围条 | 「夜 · 夜账」 | 时段不扣次数（**本稿默认混合制**） |
| 左上 · AP | `AP {AP_left}/{AP_max}`【示例】6 | 隐藏日 AP；可显示「本夜已接 {n}」 | 夜不耗日 AP |
| 中上 · 资源摘要 | `M` `S` 数字；`C`/`H` 淡色短条 | 同左；强调 `H` 环境 | 见 02 呈现约束 |
| 中上 · 口碑 | `Ty` 日页条 | `Tn` 夜页条；可并排淡显 Ty | **禁止合成单一好感** |
| 右上 · 紧张态灯 | 最严重一条图标（炸街>镇虚>脏铺/没人帮/紧巴） | 同左 | 点开看说明气泡 |
| 下 · 入口条 | 订单 \| 账本 \| 街巷 \| 伙计 \| 菜单 | 夜单 \| 账本 \| （街巷灰）\| 人情 \| 菜单 | 夜履约内整条收起或仅菜单 |

### 2.3 主菜单与设置

| 项 | 规则 |
| --- | --- |
| 继续 | 有合法最近档则亮；无则灰，气泡「还没有可续的档」 |
| 新的一局 | 有进度时二次确认「会另开存档槽，不覆盖除非自选」 |
| 读档 | 进存读档列表 |
| 设置 | 音量、字幕、闪烁减弱、复玩跳过教学开关 |
| 退出 | 二次确认 |

设置不改规则数值；「跳过教学」仅影响纯 UI 说明步（见 11）。

### 2.4 存读档

沿用 01：**本稿默认**夜履约现场禁止检查点存档。

| 时机 | 手动存 | 自动存【建议】 |
| --- | --- | --- |
| 日档柜台 | 是 | 每次重大结算后可选静默 |
| 夜接单界面 | 是 | 落锁进入夜接单时 |
| 夜履约现场内 | **否**（按钮灰） | 不写现场中途档 |
| 坏结局后 | — | 引导读「上一日日初」 |

存档槽展示：镇日序号、日/夜态、`M`/`Ty`/`Tn`/`H` 摘要、时间戳（用户时区展示由壳负责）。

### 2.5 账本（阳/夜分栏）

| 页 | 内容 |
| --- | --- |
| 日页 | 阳单流水、进货、送礼、`Ty` 变化摘记、长辈批注入口 |
| 夜页 | 诡单流水、bridge 订金、履约结果、`Tn`/`H` 摘记、可知禁忌笔记 |
| 黄历角 | 氛围「今日宜忌」文案【开放是否有全局修正，见 05】；默认只叙事 |

### 2.6 地图 / 街巷

| 规则 | 内容 |
| --- | --- |
| 形态 | 点选式街巷图（非大地图探索） |
| 日档点 | 本铺柜台、镇集、林医馆、柳裁缝铺、居委会（吴）、阿杰常出没点、对门香火店、闲聊街角 |
| 夜档 | 街巷入口默认灰显：「夜里别晃荡」；履约场景由接单进入，不经街巷闲逛 |
| 消耗 | 进入进货/打听/送礼等点并确认动作时扣 AP（见各模块）；纯打开地图不扣 |

### 2.7 通用弹层 / 二次确认 / 拦截

| 类型 | 何时 | 模板【文案待填可换】 |
| --- | --- | --- |
| 灰显原因气泡 | 长按或悬停灰按钮 | 「现在不行：{reason}」 |
| 拦截 toast | 点击无效操作 | 短句 ≤20 字，如「AP 不够」「履约中不能存档」 |
| 二次确认 | 落锁、拒被盯单、跑路、揭穿、删档、新局 | 标题 + 后果一行 + 确认/取消 |
| 结算摘要卡 | 日末/夜末/单笔交货 | 资源 Δ 列表 + 具名后果一行 |

**常见 reason 对照名**：`no_AP` / `period_locked` / `save_forbidden_fulfill` / `nerve_refuse_night` / `dirty_rite_locked` / `need_S_short` / `story_lock`。

### 2.8 日→夜 / 夜→日交接仪式屏

| 仪式 | 步骤（壳层演出，结算逻辑见 02） |
| --- | --- |
| 落锁 | 玩家点「落锁营业」或傍晚强制 → 遮罩 → 账本翻夜页动画 → 日末结算摘要（可点跳过摘要，不可跳结算）→ 进夜接单 |
| 收摊 | 夜待办清空或收摊检通过 → 夜末结算摘要 → 口碑两行动画 → 次日日初淡入；若坏结局则切 `BAD_END` |

### 3.2 文案占位约定（壳层）

- 按钮主词短：接、拒、落锁、收摊、存档。  
- 后果放确认框第二行，不塞进主按钮。  
- 夜壳默认关闭「轻快」音效主题；顶格夜关闭冷幽默收束（见 04）。

## 4. 操作流

### 4.1 启动 → 日档

1. Logo → 主菜单。  
2. 「新的一局」→（可选难度/跳过教学）→ 开场短过场 → `DAY_SHOP` 柜台。  
3. 「继续/读档」→ 校验槽合法 → 落入存档标记的壳状态（不得落入 `NIGHT_FULFILL` 中途；若坏档则回接单或日初）。

### 4.2 HUD 入口

| 点击 | 日档 | 夜接单 | 履约现场 |
| --- | --- | --- | --- |
| 订单/夜单 | 打开订单列表 | 夜池 | 不可（或仅只读本场目标） |
| 账本 | 打开账本 | 打开（只读强调） | 灰：`save_forbidden` 同类「履约中勿翻账」 |
| 街巷 | 打开街巷 | 灰：「夜里别晃荡」 | 隐藏 |
| 伙计/人情 | 伙计面板 | 人情卡列表 | 现场内改走三件套人情槽 |
| 菜单 | 暂停 | 暂停 | 暂停（存档按钮灰） |

### 4.3 落锁

1. 点「落锁营业」或时段耗尽强制。  
2. 若有未交逾期阳单：弹确认「未交货将失败结算，仍落锁？」  
3. 进 `UI_LockRitual` → 结算 → `NIGHT_BOARD`。  
4. 自动存：夜接单点。

### 4.4 收摊

1. 若仍有已接未履约夜单：拦截「还有夜账没了」或引导进现场。  
2. bridge 未履约按失败结算（04）后才允许收摊。  
3. `UI_CloseRitual` → 坏结局检 → 日初或 `BAD_END`。

### 4.5 异常态汇总（壳）

| 操作 | 拦截 |
| --- | --- |
| 履约中存档 | 灰 + toast「履约中不能存档；读档会回夜接单」 |
| AP=0 点耗 AP 动作 | 灰 +「今天只够办这些了」 |
| 夜点街巷 | 灰 +「夜里别晃荡」 |
| 无存档点继续 | 灰 |

## 5. 反馈

| 事件 | 反馈（策划级） |
| --- | --- |
| 日→夜翻页 | 纸页摩擦 SFX；色温转冷；短镜头推账本 |
| 夜→日 | 门闩/鸡鸣类远景；色温暖回；Ty/Tn 两行依次亮 |
| 紧张态升级 | 灯色一跳；可选极轻震动（可关） |
| 拦截 toast | 短木鱼/叩桌 SFX，不吓人 |
| 二次确认危险 | 底噪略静；确认键用实心、取消描边 |
| 顶格夜进入 | 环境音削薄；冷幽默 BGM 层关掉 |
