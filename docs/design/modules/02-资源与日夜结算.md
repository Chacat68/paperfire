## 1. 模块目标与玩家感受

- 钱和料是账本上的数；洁净、阴气更多靠铺面气味、街谈、黄历气氛传达。
- 镇民信任与夜口碑是两行，合不成一个「好感」。
- 夜里搞砸，第二天阳客会少、伙计会怯；白天做稳，夜里才敢接硬单。
- 落锁/收摊时有一张清楚的「今天账怎么结」摘要，玩家感到经营闭环。

## 2. 规则全文

### 2.1 资源一览

| 资源 | 显示名【建议】 | 范围【示例】 | 开局【示例】 | 日档主用途 | 夜档主用途 |
| --- | --- | --- | --- | --- | --- |
| Money `M` | 现金 | 0～9999 | 80 | 进货、议价空间、送礼、洗把柄 | 少直接花；可雇临时护法 |
| Stock `S` | 材料（普通） | 0～99 | 12 | 阳面工艺 | 可挪阴面赶工（常掉洁净） |
| Clean `C` | 洁净度（料/铺） | 0～20 | 8 | 精工产出 | 解锁「正统仪轨」档选项 |
| Favor `F` | 人情（抽象池） | 0～15 | 2 | 送礼、请人 | 履约耗抽象点或配合具名卡 |
| Haunt `H` | 阴气（越低越好） | 0～20 | 3 | 阳犯规轻抬 | 夜单主涨跌 |
| Trust_Yang `Ty` | 镇民信任 | 0～20 | 4 | 阳单流量、议价 | 夜砸盘会跌 |
| Trust_Yin `Tn` | 夜口碑 | 0～20 | 1 | — | 诡单流量、老人认可、仪轨解锁速度 |
| Nerve `N` | 伙计胆量 | 0～10 | 5（无伙计则藏） | — | ≤2 拒夜班；影响产能 |

**呈现约束**：

- `M`/`S`：账本数字。  
- `C`/`H`：环境与街谈为主，账本可给淡色条，避免 RPG 大面板。  
- `Ty`/`Tn`：日页/夜页两行，禁止合成单一好感。  
- `F`：抽象池 + 具名人情卡列表（07）。  
- `N`：伙计气泡/拒夜台词；无伙计时 UI 隐藏。

### 2.2 日末 → 夜初结算（落锁时自动）

固定顺序（不可打乱）：

| 步 | 动作 |
| --- | --- |
| 1 | `H := H + min(2, day_offense)` |
| 2 | 已接未履 `bridge` 推入夜账待办；**不另加 H** |
| 3 | `S`、`C` 原样带入夜档 |
| 4 | 清空 `day_offense` |
| 5 | 按 04、07 生成夜单池 |
| 6 | 应用延迟到落锁的具名标记 |

### 2.3 夜末 → 次日日初结算

对每一笔已结算夜单按结果类型写回，再全局收尾。

| 结果类型 | 【示例】写回 |
| --- | --- |
| 成功（普通） | `M+`；`H-1`（下限 0）；`Tn+1` |
| 成功（顶格） | 同上 + `Tn+2`；可能信物（10） |
| 压下 | `M` 半报酬；`H` 不变或 +1；把柄 1～3 日（默认拒被盯把柄 3 日，见 04） |
| 失败（普通） | `M` 无或少；`H+2`；`Ty-1`；`N-2`；1 个具名议论 |
| 失败（顶格） | `H+4`；`Ty-3`；`N-4`；可能贴条/封门 1 日 |
| 拒接所有夜单 | `H+0`；`Tn` 不涨；池中有「被盯」未处理则 `H+1` |
| 跑路 | 普通失败 + `Tn-1`；目击者脸 → 具名后果 |

**全局收尾**：汇总 clamp → 持续标记日数 -1 → 坏结局检（06）→ 否则次日日初刷新阳单。

### 2.4 资源紧张态

| 状态 | 条件【示例】 | 玩家感到 | 系统效果【建议】 |
| --- | --- | --- | --- |
| 紧巴 | `M<30` 或 `S<5` | 只能接短交期小单 | 长交期/高 need_S 警告或权重下降 |
| 脏铺 | `C<4` | 夜仪轨只剩歪办 | 正统仪轨锁定 |
| 没人帮 | `F=0` 且无可用具名卡 | 顶格极难 | 人情槽仅硬扛 |
| 镇虚 | `H≥12` | 夜单变凶；日客发虚 | 夜 risk 权重↑；对白换套 |
| 炸街 | `H≥18` | 强制顶格候选；近坏结局 | 04、06 |

UI 优先提示最严重一条：炸街 > 镇虚 > 脏铺/没人帮/紧巴。

### 2.5 相对大小（平衡前只锁）

夜报酬 > 阳报酬；顶格威胁与失败创伤 > 普通夜；白天补救总成本 < 一次顶格失败创伤。

## 4. 操作流

### 4.1 玩家如何「看到」结算

1. 落锁 → 仪式中弹出日末摘要卡（可点「继续」，不可改数）。  
2. 收摊 → 夜末摘要：先逐单展开/收起，再总览。  
3. 点紧张态灯 → 气泡解释条件与「现在怎么办」（指向补救/进货/打听，不自动传送）。

### 4.2 异常态

| 情况 | 表现 |
| --- | --- |
| 资源触顶 | toast「堆不下」/`H` 已顶格发黑 |
| 无伙计 | N 整栏隐藏，不显示 0 |
| 结算中点菜单 | 允许开设置；存档按 01 边界 |
