## 1. 模块目标与玩家感受

- 白天柜台：接单、议价、备料、交货，反馈快，可冷幽默。
- 阳忌是彩头和规矩级别——犯规主要丢人丢信任，不轻易把阴气拉满。
- 精工攒洁净、赶工省交期但埋隐患；料会留给夜里用。

## 2. 规则全文

### 2.1 订单公共字段（阳/诡/桥共用子集）

| 字段 | 说明 |
| --- | --- |
| `id` / `face` | 模板 ID；绑定角色脸 |
| `realm` | `yang` \| `yin` \| `bridge` |
| `pay_base` | 基础报酬【示例】 |
| `due` | 当日傍晚 / 次日 / （桥）夜当场 |
| `need_S` / `need_C` | 材料与洁净需求 |
| `taboos[]` | 禁忌（阳多为轻忌） |
| `risk` | 0～3；阳通常 0～1 |
| `tags` | 红白/符/净宅/寻物/送行… |

### 2.2 阳单流程

```
午前刷新 → 接/拒/议价 → 备料（正料|替代，精工|赶工|普通）→ 交货 → 结算
```

| 阶段 | 条件/规则 | 边界 |
| --- | --- | --- |
| 刷新 | 每镇日日初；数量受 Ty 与角色加权 | 剧情强制单可单列 |
| 接单 | 锁定预计 need_S；不足标替代料意向 | 交期进待办 |
| 拒单 | 一般无罚；陈婶/支书关键介绍拒有轻罚 | 【示例】Ty-1 或下次少 1 单 |
| 议价 | 每单至多 1 次；看 Ty 与 face | 成功 +10%～20% **或** 长交期 |
| 备料 | §2.3；占 1 AP/批次 | — |
| 交货 | 柜台或上门；检轻忌 | — |
| 逾期 | 交期到未交货 | 失败；可求情延期 1 次耗 F |

### 2.3 工艺选择

| 模式 | 支付 | 效果【示例】 | 边界 |
| --- | --- | --- | --- |
| 普通 | need_S；need_C 满足则洁净档 | 无额外 | 默认 |
| 赶工 | -1C **或** day_offense+1 | 省 1 档交期 | 最短交期不可再赶 |
| 精工 | 额外 -S【示例】+2；成功 C+1 | 交货 Ty 额外 +1 | S 不足不可精工 |
| 替代料 | 见 08；成品 dirty/proxy | 阳或掉 Ty；转夜抬 Threat | 少强制 |

### 2.4 阳间轻忌

犯规：`day_offense += 1`；日末 `H += min(2, day_offense)`；严重可当场 Ty-、无报酬。

| code | when | 描述 | break_cost【示例】 |
| --- | --- | --- | --- |
| `no_joke_funeral` | 交货 | 白事勿笑场 | day_offense+1；严重 Ty-1 |
| `no_flash` | 接谈/交货 | 勿让阿杰闪光灯拍成品 | day_offense+1；传播挂阿杰线 |
| `zodiac_block_white` | 交货 | 属相日不交白事 | 改期或 day_offense+1 |
| `no_dead_bargain` | 议价 | 勿讲价讲死气 | 议价失败 + day_offense+1 |

### 2.5 交货结算

| 结果 | 【示例】 |
| --- | --- |
| 成功 | M+pay；Ty+1（首次帮某 face +2） |
| 成功+精工 | 上 + Ty 额外 +1 |
| 失败/严重犯规 | M 无；Ty-2；轻忌仍入日末 |
| 陈婶线成功 | 推进介绍权/人情 |

### 2.6 bridge 日档侧

日档收订金【示例】30%～50% pay_base 计入 M；夜强制履约见 04。  
**本稿默认**：重要剧情脸每 2～3 镇日 ≤1 张 bridge。

### 2.7 样例单

同 v0.1：陈婶白事纸扎；吴支书合规净宅（可 bridge）。

## 3. 界面与信息架构

| 屏 ID | 名称 | 布局要点 |
| --- | --- | --- |
| `UI_YangOrderList` | 今日阳单列表 | 脸缩略、报酬、交期、risk 点、bridge 角标 |
| `UI_YangTalk` | 接谈弹层 | 左立绘+对白；右单卡字段；底接/拒/议价 |

文案占位：`「交期：{due}」`；`「需要料 {need_S}」`；`「这单夜里还要再办」`（bridge）。

## 4. 操作流

### 4.1 接单

1. 柜台/订单入口 → 列表。  
2. 点单 → 接谈弹层（可知轻忌列出）。  
3. `[接]`：预检 S；不足则确认「将使用替代料意向」→ 锁料 → 扣 1 AP（整次接谈链）。  
4. `[拒]`：一般直接拒；关键脸 → 确认轻罚。  
5. `[议价]`：若本单已议过则灰；成功选报酬或交期；失败可记轻忌。

### 4.2 备料

1. 待办「待备料」→ 工艺屏。  
2. 选普通/赶工/精工；赶工再选代价（-C 或轻忌）——按单 tags 可强制一种。  
3. S 不足精工 → 精工灰 `need_S_short`。  
4. 确认 → 扣 AP（若未与接谈合并批次规则）→ 成品进待交货。

### 4.3 交货

1. 点交货 → 轻忌选项（如「是否笑场」「是否允许拍照」）。  
2. 危险选项二次确认或强警告。  
3. 结算摘要 → 回柜台。

### 4.4 异常态

| 情况 | 拦截 |
| --- | --- |
| AP=0 | 接谈/备料灰 |
| 最短交期赶工 | 赶工灰「已经来不及再赶」 |
| 关键关键拒 | 确认框列出 Ty 后果 |
| 逾期 | 日末/交期点自动失败或弹求情（耗 F） |
