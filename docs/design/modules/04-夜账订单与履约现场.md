## 1. 模块目标与玩家感受

- 夜里是另一本账：报酬高、规矩狠；多数单可算计，偶发顶格才真正静下来高压。
- 履约是短现场：用规矩/道具/人情把局面压下去，不是砍怪。
- 可以少接、可拒（被盯除外有代价）、可跑路——经营选择本身就是降压。

## 2. 规则全文

### 2.1 夜单（yin）流程

```
落锁后刷新夜池 → 接/拒/加价 →（可选连夜备阴面）→ 履约现场 → 单笔结算 → 收摊总结算
```

| 动作 | 规则 | 【示例】 |
| --- | --- | --- |
| 刷新数量 | 受 Tn、H、角色加权 | 基础 1；Tn≥5 可 2；H≥12 强制 ≥1「被盯」 |
| 顶格标记 | 每 3～5 镇日 ≤1；节气可强制 | §2.5 |
| 拒单 | 可拒；「被盯」拒则惩罚 | H+1，留把柄 |
| 加价 | 夜可更狠 | +20%～40%，risk+1 |
| 接单瞬间 | 锁定 need_S | 不足自动替代料 |
| 连夜备阴面 | 可选 | 花 C 洗料或做符 |

### 2.2 bridge · **本稿默认**

| 规则 | 内容 |
| --- | --- |
| 日档 | 订金 30%～50% pay_base |
| 夜档 | 待办置顶，优先展示；必须履阴面 |
| 未履约 | 视同夜失败（普通） |
| 频率 | **重要剧情脸每 2～3 镇日 ≤1 张** |

### 2.3 被盯拒单把柄 · **本稿默认**

- 拒「被盯」：`H+1` + 把柄标记。  
- 把柄持续 **3 镇日**。  
- 可花钱洗 **1 次/周**【示例】（日档铺务或账本入口；耗 M【示例】与紧张态相关）。

### 2.4 履约现场 · Threat · **本稿默认回合制**

> **相对变更**：主流程锁定回合制；一次性三槽仅 §8 备选，不进主 UI。

进入现场后 Threat【示例】1～5。  
`Threat0 = risk + clamp(H/6,0,2) + (替代料?1:0) + (顶格?2:0)`，再 clamp。

**回合制**：每回合选 1 手段，直到胜/败/压下/跑路；普通夜最多 **4** 回合，顶格 **3**【示例】。

| 手段 | 支付 | 效果【示例】 | 失败/错选 |
| --- | --- | --- | --- |
| 规矩 | 已解锁仪轨；可耗 C | Threat-2 | Threat+1 且 H+1 |
| 道具 | 预做符/成品/S | Threat-1；脏料同 -1 但 H+1 | 无道具不可选 |
| 人情 | F 或具名卡 | Threat-2；卡带特殊解 | 无卡花 2F→仅 Threat-1 |

**胜利**：选项耗尽前 Threat≤0，且完成主目标条。  
**压下**：双倍人情或指定具名代价，强制 Threat=0，走压下结算。  
**失败**：Threat 仍高且回合耗尽，或跑路。  
**跑路**：普通失败 + Tn-1；目击者脸 → 具名后果。

检定顺序：进现场 → 揭示本场可知/未打听 hidden → 选手段（回合）→ 主目标检 → 结算。

### 2.5 顶格夜

频率 3～5 镇日 ≤1；少 1 通用手段；错规矩惩罚加倍；文案更静；冷幽默收束关；优先耗柳卡。

### 2.6 样例与标签

同 v0.1：吴便装安魂；阿杰删图安神。模板标签：阴面送行、安魂、两套账、纸人自行、寻不该寻之物、庙拆无名、删图、拒诊转介等。

## 4. 操作流

### 4.1 夜接单

1. 落锁后进入夜池。  
2. 点单 → 可知重忌列表；`[加价]`/`[接]`/`[拒]`。  
3. 拒被盯 → 二次确认：「会被盯上，阴气+1，把柄约 3 日」。  
4. 接 → 锁料 →（可选备阴）→ `[赴约]` 进现场。  
5. 现场内：菜单可开，**存档灰**。

### 4.2 回合制履约

1. 开场：Threat 初值动画；揭示未打听 hidden（插页）。  
2. 每回合：点规矩/道具/人情之一 → 若多选规矩则展开仪轨列表 → 确认。  
3. 错选 → Threat/H 反馈 → 下一回合。  
4. Threat≤0 且目标完成 → 胜利结算。  
5. 回合用尽仍 Threat>0 → 失败。  
6. `[压下]` / `[跑路]`：二次确认列后果。

### 4.3 收摊

待办（含 bridge）全部有终态 → 收摊启用；否则拦截。

### 4.4 异常态

| 情况 | 拦截 |
| --- | --- |
| 无解锁正统仪轨且 C 脏 | 规矩仅歪办档或灰部分条目 |
| 无道具 | 道具列灰 |
| F=0 且无卡 | 人情仅提示硬扛/不可抽象降足够 |
| 履约中存档 | 灰 |
| 洗把柄超周次 | 灰「这周已经洗过」 |
