## 1. 模块目标与玩家感受

- 阳忌像乡俗彩头；夜忌像真规则书——不知比硬闯更致命。
- 洁净是夜里正统仪轨的门票；脏铺只剩歪办，风险自己清楚。
- 阴气高了，街上话发虚、夜单变凶，而不是血条归零。

## 2. 规则全文

### 2.1 禁忌条目字段

| 字段 | 说明 |
| --- | --- |
| `code` | no_photo / month_block / no_third / no_record… |
| `realm` | yang \| yin \| both |
| `severity` | light \| heavy |
| `when` | accept / craft / fulfill |
| `visible` | known \| hidden |
| `break_cost` | H+、锁选项、结局支、具名标记 |
| `hint` | 外乡可见短提示 |

### 2.2 可知 vs 隐藏

| 类型 | 何时看到 | 如何提前知道 |
| --- | --- | --- |
| 可知 | 接单界面列出 | 默认；账本旧注可补 |
| 隐藏 | 履约中途揭示 | 日档打听：1 AP + F 或求柳，揭示某单 1 条 |

检定顺序：接单可知 → 备料 craft → 履约揭示剩余 hidden → fulfill 检。

### 2.3 阴气 H

| 来源 | 【示例】 |
| --- | --- |
| 日档轻忌 | 日末 H += min(2, day_offense) |
| 夜错规矩 | 当场 H+1（顶格加倍） |
| 脏料道具 | H+1 |
| 拒被盯 | H+1 |
| 夜失败 | 普通 +2；顶格 +4 |
| 成功履约 | 普通 H-1（下限 0） |
| 上界 | 20；≥12 镇虚；≥18 炸街；≥20 坏结局条件之一 |

**不做**：白天正常经营把 H 当主惩罚。

### 2.4 洁净 C

用途：精工；正统仪轨；need_C。  
获得：精工成功 +1；林医生洁净料；特定阳奖。  
消耗：赶工 -1；规矩耗 C；脏铺事件。  
脏铺：C<4 → 夜仪轨只剩歪办。

### 2.5 仪轨档

| 档 | 解锁【示例】 | 效果 |
| --- | --- | --- |
| 歪办 | 默认 | 弱规矩或附带 H+ |
| 正统 | C≥4 且柳已教第 1 条（约 D3） | Threat-2 |
| 老人认可 | Tn≥5 / ≥10 | 特定 tags 额外 -1 或免隐忌一次 |

错选：Threat+1 且 H+1；顶格加倍。

### 2.6 重忌示例

no_record / no_third / no_photo / month_block / true_name —— 同 v0.1d。尺度：发忌/错身/纸人自行；避免过度血腥与宗教照搬。

### 2.7 洁净仪轨（补救用 · 与 06「不对劲」清除咬合）

**本稿默认**：清除「不对劲」需连续 2 个无顶格失败镇日 **+ 做 1 次洁净仪轨**。  
洁净仪轨【示例】：日档铺务，耗 C 与 AP（或指定材料），成功给叙事反馈；不直接大砍 H（可微降【示例】H-1）。

## 3. 界面与信息架构

| 屏 | 用途 |
| --- | --- |
| 接单禁忌条 | known 列表；hidden 显示「？」或「打听可知」 |
| 账本夜页笔记 | 已揭示禁忌归档 |
| 仪轨选择列表 | 履约规矩▼展开；锁档灰显 reason |
| 环境 H/C | HUD 淡条 + 铺面 VFX |
| 洁净仪轨确认 | 铺务入口 |

文案：`「正统仪轨未开：洁净不足或柳未传授」`；`「歪办：能用，但邪门」`。

---

## 4. 操作流

1. 接单：读 known；点「？」可跳转打听（若有 AP）。  
2. 备料：触发 craft 忌 → 选项改期/硬做。  
3. 履约：开场插页翻 hidden → 写入本场已知列表。  
4. 选规矩：列表按档分组；未解锁灰 + 气泡。  
5. 洁净仪轨：街巷/铺务 → 确认耗材 → 成功标记 `cleansing_done`（供 06）。

异常：脏铺时正统全灰；顶格错选双倍反馈强制播完再续。
