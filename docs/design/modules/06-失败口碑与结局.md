## 1. 模块目标与玩家感受

- 失败优先变成「谁在议论你、谁不再介绍、伙计拒夜」，而不是抽象 -10。
- 普通失败白天能补；顶格失败才真正伤筋动骨。
- 坏结局短、可读档回上一日日初——小品允许重来，不鼓励现场重 roll。

---

## 2. 规则全文

### 2.1 双口碑

| | Ty 镇民信任 | Tn 夜口碑 |
| --- | --- | --- |
| 涨 | 阳交货、陈婶线、公开圆场 | 诡成功、柳认可、守密 |
| 跌 | 夜失败外溢、阿杰传播、支书日查 | 拒被盯、泄夜密、跑路 |
| 影响 | 阳单数量、议价、封门、介绍 | 诡单数量、仪轨速度、童引 |

交叉：夜失败常双跌；揭穿吴：Ty+2 但 Tn-3、吴退夜池；表面守密可勒索 1 次 bridge，失败双跌。

### 2.2 具名后果表

| 触发 | 具名后果【示例】 |
| --- | --- |
| 夜失败 × 阿杰 | 镇群传闻；次日阳刷新 -1 |
| 夜失败 × 吴 | 日间抽查；强制低价阳单 |
| 夜失败 × 伙计在场 | N-3；拒夜台词 |
| 跑路 × 目击者 | 该脸对白改套 + 上列 |
| N≤2 | 不可带伙计履约；产能 -1 |
| Ty≤2 | 陈婶暂停介绍 |
| Ty=0 | **本稿默认**：先 **假死一晚**（次日仅糊口小单/强提示），再并入破产检 |
| 顶格失败 | 贴条/封门 1 日；少单 |
| 把柄 | **默认持续 3 日**（04）；被盯权重↑；可洗 1/周 |
| H≥18 连续 2 夜 | 坏结局检定 |

做表字段：`trigger` / `duration_days` / `resource_delta` / `flag` / `ui_bark`。

### 2.3 坏结局门槛【示例】· **本稿默认细则**

任一条：

1. `H≥20`  
2. `Ty=0` 且 `Tn=0` 且现金破产（`M=0` 且 `S=0`）——经 Ty=0 假死一晚流程后仍满足则触发  
3. 顶格失败且已有「不对劲」标记  

流程：夜末或触发点 → 短过场（易主/离开）→ 读档回 **上一日日初**。

**「不对劲」标记**：

| | 本稿默认 |
| --- | --- |
| 获得 | 顶格失败；或 `H≥18` 曾持续一晚后挂上 |
| 清除 | 连续 2 个**无顶格失败**的镇日 + 做 1 次洁净仪轨（05） |

### 2.4 普通失败补救菜单

次日日档明确「白天还能补」：

| 补救 | 效果【示例】 | 成本感 |
| --- | --- | --- |
| 低价阳单 ×2 | 回 M | 耗接谈 |
| 送礼 | 回 F | M+AP |
| 精工 | 回 C | 额外 S |
| 主动低 risk 夜单 | 回 Tn | 次夜 |

补救总成本 < 一次顶格失败创伤。

### 2.5 阳失败 vs 夜失败

阳主砸 M/Ty；夜主砸 H/Tn/Ty 外溢/N/具名；坏结局走顶格/炸街路径。

## 3. 界面与信息架构

| 屏 | 用途 |
| --- | --- |
| 具名后果条 | 结算卡内一行 + 次日街谈气泡 |
| `UI_Remedy` | 补救菜单（日初或账本提示入口） |
| `UI_BadEnd` | 短过场 +「回到上一日」 |
| 不对劲标记 | HUD 小符号；点开清除进度 |
| 封门态 | 日档柜台贴条叠层；订单刷新减少 |

文案：`「白天还能补」` 固定入口句；坏结局不长篇。

---

## 4. 操作流

### 4.1 失败后次日

1. 收摊摘要列出具名后果。  
2. 日初若存在可补救标记 → 自动或手动打开 `UI_Remedy`。  
3. 玩家选补救项 → 走对应模块操作流（接单/送礼/精工）。

### 4.2 坏结局

1. 检定通过 → 锁操作 → 过场。  
2. 唯一主按钮「回到上一日日初」→ 读系统档。  
3. 不提供「现场重来」。

### 4.3 洗把柄

账本/铺务 → 价目 → 确认耗 M → 清把柄；超次灰显。

### 4.4 异常态

| 情况 | 拦截 |
| --- | --- |
| 封门日想接高价阳 | 列表少单/部分灰「贴条中」 |
| 不对劲未清又顶格失败 | 坏结局 |
| Ty=0 假死夜 | 强提示糊口；尚未直接 BAD_END |

## 8. 开放点 / 待 Charlie 拍板

1. 坏结局是否过狠——**本稿沿用门槛；开放「是否过狠」可再削**。  
2. 不对劲获得/清除——**本稿默认已写入 §2.3**。  
3. Ty=0——**本稿默认假死一晚再并入破产检**。  
4. 一周目加严忌与坏结局——通关后占位。  
5. 信物挡封门——**本稿默认不挡（10）**。
