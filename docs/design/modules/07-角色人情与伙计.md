## 1. 模块目标与玩家感受

- 重要单都绑得住人：口头禅、物件、站位认人，不靠好感度数。
- 同一张脸日夜可以两套事——吴支书是样板错位。
- 人情是「叫谁来」比抽象点数更有故事；伙计怕了会拒夜班。
- 对门香火店是利益动物邻居，抢单压价、甩锅共背，不是灭门对象。

## 2. 规则全文

### 2.1 常驻镇脸功能接口

| 脸 | 阳功能 | 夜功能 | 玩法摘要 |
| --- | --- | --- | --- |
| 陈婶 ★ | 介绍邻居单、闲话抬 Ty | 极少；小阴事冷幽默 | 阳中介、人情缓冲 |
| 吴支书 ★ | 合规/净宅；反封建话术 | 便装塞红包、老规矩 | 错位样板；揭穿/保密 |
| 柳裁缝 ★ | 挑剔工艺、教轻忌 | 顾问：解锁仪轨，欠愿 | 知识商人；顶格优先耗 |
| 阿杰 ★ | 拍摄改装、快工、科学说法 | 删图/安神；可顶格引线 | 轻忌冲突；传播具名 |
| 纸马童 ★ | 几乎不说话；递错东西 | 接待/带路；童引单 | **本稿默认终局解释：旧愿**；一周目主线走旧愿；非人看门/长辈错身为备选枝 |
| 林医生 | 符与洁净阳单；卖洁净料 | 拒诊转介；日间装瞎 | 材料商 + 装瞎 |
| **对门香火店** | 抢单压价 | 甩锅/共背 | **本稿默认进常驻**；影响镇脸加权与脏料进货；**不做可灭门主线** |
| 已故长辈声音（可选） | 工艺提示 | 禁忌提示；不出影 | 教程锚 |
| 一次性脸 | 补数量 | 补数量 | 脸谱化 |

重复：常驻脸主线相关至少每 2～3 镇日露 1 次。夜事主优先常驻变形。

### 2.3 具名人情卡

| 卡 | 获得【示例】 | 效果 | 消耗 |
| --- | --- | --- | --- |
| 叫柳裁缝 | 欠愿或 F-2 | Threat-3；揭 1 隐忌 | 冷却/再欠愿 |
| 陈婶圆场 | F-1 + 线进度 | 非顶格；改目击者议论 | 一次性或冷却 |
| 支书盖章 | 完成 1 次错位单 | 日免抽查 1；夜用 Ty-1 | 标记消耗 |
| 纸马童带路 | 童信任 | 跳过 1 迷路/错身检 | 剧情限次 |

抽象 F：无卡花 2 点临时外人 → Threat-1。  
卡字段：`owned` / `charges` / `cooldown_days` / `story_flag`。

### 2.4 揭穿 / 保密（吴）

| 选择 | 【示例】 |
| --- | --- |
| 夜接并守密 | M+；Tn+1；wu_secret |
| 日间揭穿 | Ty+2；Tn-3；吴退夜池 |
| 表面守密日间拿捏 | 可勒索 1 bridge；失败双跌 |

### 2.5 伙计与 Nerve N

开局可独自夜班；有伙计才显示 N（开局 5）。夜失败在场 N-；N≤2 拒夜班、不可带履约、产能-1。安抚：日档铺务耗 M 或 F，N+1。专属夜伙计为开放点。

### 2.6 对门香火店 · **本稿默认开**

阳竞争压价；夜甩锅/共背；脏料进货源（08）；不做纯反派、不做灭门主线。

## 4. 操作流

### 4.1 人情卡在履约

1. 点人情 → 列出可用卡 + 「临时外人 (F-2)」。  
2. 不可用灰：冷却/顶格限制（陈婶圆场）。  
3. 确认 → Threat 结算 → 卡消耗。

### 4.2 安抚伙计

1. 伙计面板 → 安抚 → 选耗 M 或 F → N+1。  
2. N≤2 时夜带伙计按钮灰：「他不敢上夜」。

### 4.3 揭穿吴

1. 日档与吴对话出现选项（教学期可警告）。  
2. 二次确认列双口碑后果。  
3. 执行改池与标记。

### 4.4 异常态

| 情况 | 拦截 |
| --- | --- |
| 无卡无 F | 人情手段不足提示 |
| 香火店灭门类幻想选项 | **不提供** |
| 纸马童身份追问过早 | 模糊回绝；不剧透旧愿 |
