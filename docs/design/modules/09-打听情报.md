## 1. 模块目标与玩家感受

- 外乡不懂全套规矩：打听是「花钱花面子换少踩雷」，不是百科按钮。
- 知不知道隐忌，夜里手段差一截——信息差即难度。
- 找柳、找陈婶闲话、找账本批注，味道不同，带冷幽默。

---

## 2. 规则全文

### 2.1 打听动作

| 规则 | 内容 |
| --- | --- |
| 时段 | 仅日档；夜履约中不开放查攻略式打听 |
| 成本 | 【示例】1 AP + 可选 F-1 或欠人情（柳渠道常要） |
| 次数 | 【示例】每镇日最多 2 次 |
| 目标 | 某张已刷新未履约单 / 某常驻脸 / 某禁忌主题 |

例外：履约中「叫柳」卡可揭 1 隐忌——算卡效果，不算打听。

### 2.2 渠道

| 渠道 | 条件 | 产出 | 语气 |
| --- | --- | --- | --- |
| 账本旧注 | 教程后默认 | 可知补强；偶发模糊隐忌线索 | 短、不出影 |
| 柳裁缝 | 认识后；常要 F/旧愿 | 精确揭 1 hidden 或仪轨碎片 | 挑剔、黄历腔 |
| 陈婶闲话 | Ty 不太低 | 阳背景、忌口；极少夜忌 | 保温袋关心 |
| 林医生 | 认识后 | 洁净/科学说法线索；转介预警 | 消毒水腔 |
| 阿杰 | 有交往 | 传播风险预警 | 短视频腔 |
| 街谈 | 默认 | 随机轻线索；可能空话 | 嘈杂 |

### 2.3 情报类型

揭示隐忌（hidden→known）；仪轨碎片；人脸情报；风险预警；空话（仍耗 AP，连续同渠道空话权重↑）。

单次默认 **1** 条有效情报；不可一次掏空（除非剧情旗）。

### 2.4 与接单/履约咬合

日刷新 →（可选打听）→ 接单（可知已含结果）→ 夜履约（未揭示 hidden 仍翻出）。

拒听合法；高 risk/顶格 UI 暗示「你爷爷夜账写过问人」。

### 2.5 不做什么

夜现场维基；打听直接降 Threat；大地图迷雾收集。小品笔记单页即可，不做大图鉴——**本稿默认**。

## 3. 界面与信息架构

| 屏 | 用途 |
| --- | --- |
| `UI_Inquire` | 选渠道 → 选目标单/脸 |
| 结果卡 | 1 条情报正文 + 写入账本按钮 |
| 订单卡「？」 | 未揭 hidden 入口捷径 |
| 账本笔记 | 已揭列表 |

文案占位：`「打听：{channel}」`；`「得知：{taboo_hint}」`。

---

## 4. 操作流

1. 街巷/订单「打听」→ `UI_Inquire`。  
2. 选渠道（不满足条件灰）→ 选目标。  
3. 预检 AP 与日次数、可选 F → 确认。  
4. 播短对话 → 结果卡 → 若揭示则订单禁忌条更新。  
5. 顶格/高 risk 未打听：接单确认旁弱提示（不强制）。

异常：夜现场打听入口不存在；AP/次数不足灰；Ty 过低陈婶拒闲话。

| 事件 | 反馈 |
| --- | --- |
| 有效揭示 | 账本批注书写；禁忌「？」变实句 |
| 空话 | 笑一下；仍扣 AP |
| 求柳 | 欠愿进度角标微动 |
| 信物铜扣免 AP | 首次打听 AP 不扣（仍可耗 F）——见 10 |

## 8. 开放点 / 待 Charlie 拍板

1. 是否必须耗 F，还是仅柳耗——**本稿默认：仅柳等「要面子」渠道耗**。  
2. 账本旧注每日是否免费 1 次模糊线索。  
3. 顶格是否强制可打听窗口提示。  
4. 情报永久图鉴——**本稿默认单页夜账笔记，不大图鉴**。
