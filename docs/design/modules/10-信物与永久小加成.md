## 1. 模块目标与玩家感受

- 信物是「这镇认你办成过难事」的物件，不是装备党数值膨胀。
- 永久小加成：省一次心、多一句提示、轻一点惩罚——压过「+50% 伤害」。
- 顶格成功或关键角色线才掉，稀缺才记得住。
- **一周目定位：打满彩蛋 / 轻量成长**，不挡封门、不挡通关。

---

## 2. 规则全文 · **本稿默认**

### 2.1 定义

| 字段 | 说明 |
| --- | --- |
| `relic_id` | 唯一 ID |
| `name` | 显示名 |
| `source` | 顶格成功 / 角色线 / 特殊夜 |
| `effect` | 永久被动或每日 1 次主动 |
| `stack` | 同 ID 只持有 1 |
| `story` | 一句来历，绑脸 |

### 2.2 获得

| 来源 | 【示例】 |
| --- | --- |
| 顶格成功 | 50% 或前 2 次顶格成功保底 |
| 普通夜 | 默认不掉 |
| 角色线 | 吴守密、柳旧愿、纸马童信任等 0～1 |
| 不可买 | 现金不买永久信物 |

### 2.3 效果约束与上限

- 优先改信息、次数、惩罚减免、刷新微权重；少改报酬倍率。  
- **同时生效上限 3**；超出进仓库仅叙事。  
- **不挡封门**（一周目）。  
- **新周目默认不继承**；开放点可留 1 件叙事物。

### 2.4 【示例】信物表

| 信物 | 来源 | 效果 |
| --- | --- | --- |
| 旧账铜扣 | 首次顶格 | 每日首次打听不耗 AP（仍可耗 F） |
| 柳指顶针 | 还柳旧愿 | 每镇日第一次错规矩免 H+1（Threat 仍+） |
| 支书空烟盒 | 守密线 | 日间抽查免 1（与盖章卡不同日叠） |
| 纸马蹄铁 | 童信任 | 每夜跳过 1 迷路/错身检 |
| 陈婶保温袋扣 | 陈婶线 | Ty≤3 时阳刷新保底 1 介绍向小单 |
| 静符残角 | 阿杰顶格安神 | 传播类失败 Ty 跌幅 -1 |
| 净瓶塞 | 林线 | 洁净包额外 C 掷 50% |

### 2.5 不做什么

套装变身；战斗伤害；赛季养成。

## 3. 界面与信息架构

| 屏 | 用途 |
| --- | --- |

文案避免「装备」「伤害」。

---

## 4. 操作流

1. 顶格/线成功结算 → 掉落检定 → 获得弹层。  
2. 若生效已满 3：弹「选择替换生效或放入仓库」。  
3. 仓库可手动装备/卸下（日档柜台；履约中只读）。  
4. 新周目：清空生效与仓库（若未来开「留 1 叙事物」则例外 UI）。

异常：履约中不可换装信物；花钱买信物入口不存在。
