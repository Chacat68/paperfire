## 1. 模块目标与玩家感受

- 先会白天开铺，再发现账本有夜页——冷幽默：「以为加班做纸人」。
- 前几小时打透：阳稳、夜险、吴支书错位、纸马童是谁（疑问即可；**旧愿**主线后期再亮）。
- 失败可补；顶格与坏结局推后，不在教学窗灌满。

---

## 2. 规则全文

### 2.1 教学原则

每步只教一个动作；能晚教不提前；文案短；复玩可跳过纯 UI 说明；剧情强制遇不可跳；外乡视角「你爷爷从前…」。

### 2.2 开局资源【示例】

`M80 S12 C8 F2 H3 Ty4 Tn1 N5`（无伙计则藏 N）。

### 2.3 前几镇日脚本目标

| 镇日 | 验证目标 | 必教切片 | 强制/建议遇 | 压力 |

### 2.6 教学窗禁止

D1 不进顶格、不进坏结局检；D1～D2 不强制揭穿吴；不大地图；不教战斗；纸马童身份不揭穿（旧愿后期）。

### 2.7 复玩/跳过

新周目可跳过 D1 UI 教学；剧情强制遇保留。读档不跳过未看过的强制遇。

## 4. 操作流（D1 逐步焦点路径）

1. 过场结束 → 遮罩点亮订单条 → 玩家点开。  
2. 接谈：仅 `[接]` 可点（拒可灰或点了被陈婶拦回）。  
3. 自动引导待备料 → 工艺屏仅「普通」高亮。  
4. 交货按钮高亮 → 结算。  
5. （可选）阿杰：闪光灯选项教学轻忌；可跳过。  
6. 傍晚或 AP 将尽 → 落锁高亮 → 翻页不可跳。  
7. 夜列表高亮 → 接或拒；拒则跳过 9，仍进 10。  
8. 若接：现场仅正确规矩高亮；其他手段可点但提示「这单先学规矩」。  
9. 收摊 → Ty/Tn 两行依次亮。

异常：玩家乱点非焦点 → toast「先看这边」；卡死超时 → NPC 催白。
