## 1. 概述

### 1.1 设计目的

本方案回答并固化下列问题，供策划、程序、文案、QA 对齐：

1. 《纸火》是什么游戏：现代化乡土小镇上的纸扎铺，**白天接阳间生意、晚上接诡异生意**；经营为主、生存为辅。
2. 玩家是谁：外乡接手祖业的坐店师傅——接单、备料、交差、还人情；不是除魔人，不是探险队长。
3. 好玩从哪来：日夜两套规则书与同一张脸两套社会面具；规矩/道具/人情压局面；失败砸铺子与人，不是血条。
4. 调性：冷幽默 + 偶发高压；尺度偏发忌 / 错身 / 纸人自行，少血腥，不照搬宗教仪轨写实。

成功标准（可读优先）：

- 读完第1～3章，能复述玩家在一个游戏日里做什么、怎么取舍、失败后怎么补。
- 读完第4章任一系统块，能按「开放条件 → 入口 → 循环 → 失败恢复」落地。
- 所有未拍板项可在附录 B 找到；正文不把【暂定】写成铁律。

### 1.3 基础结构（玩家侧一句话）

有一座正在「现代化」的小镇：路通了，手机有了，庙拆了一半，红白事还是要办。玩家从外乡回来，接手长辈纸扎铺——柜台白天卖正经彩头与纸货；账本翻到夜页，另开一栏谁都不肯当众念出来的生意。

一个**游戏日** = **白天阳间经营** + **夜里诡异经营（含履约）**。两边共用材料、人情与洁净；口碑拆成镇民信任与夜口碑两行。生存压力挂在**夜履约现场**（短场景压局面），不是单独「纯挨吓」时段。

## 2. 设计 & 通用规范

### 2.1 核心理念与调性

| 已拍板项 | 正式口径（勿标待拍板） |
| --- | --- |
| 主辅关系 | 经营为主、生存为辅 |
| 调性 | 冷幽默 + 偶发高压 |
| 主角 | 外乡接手祖业的坐店师傅 |
| 日夜生意 | 白天阳间生意；晚上诡异生意 |
| 生存落点 | 夜履约过程内，非单独挨吓阶段 |
| 故事亮点 | 日夜角色 / 同一张脸两套面具 |
| 失败形态 | 砸铺子与人（信任、伙计、客源、封门议论）；不是血条 |
| 诡异尺度 | 发忌 / 盯梢 / 错身 / 纸人自行；少血腥；不照搬宗教仪轨写实 |

设计取舍（影响后续规则选择）：

- 恐怖来自「接不接、怎么交差、知不知道规矩」，不来自走廊追逃。
- 资源同时是钱、材料、人情与洁净；夜搞砸会外溢到次日阳间。
- 人驱动订单：重要单绑得住的镇上熟人；认人靠口头禅、物件、站位，不靠好感度数。

### 2.2 世界观与诡异规则（吸收 setting）

#### 2.2.1 镇子气质与阳间秩序

镇不大，新灯箱和旧屋檐挤在一起：快递点贴着「禁止封建迷信」褪色告示，隔壁香火味不肯散。气质关键词：**现代乡土正在互相抢解释权**——短视频、工作证、黄历、保温袋四种「权威」同时有效。

白天表面秩序清楚：红白事仍要办；合规话术常在；人情走明路；科学说法是保护色。阳间不是「无诡异」，而是**诡异被礼貌地压在台面下**。轻忌像乡俗彩头：犯规多扣信任与现金，很少当场把铺子变成鬼屋。

#### 2.2.2 权力与人情（谁说了算）

镇里没有魔王，只有叠在一起的权力面孔：

| 面孔 | 白天怎么算数 | 夜里怎么算数 |
| --- | --- | --- |
| 支书一类 | 通知、抽查、合规单 | 便装、红包、不敢立案的事 |
| 老人 / 旧手艺人 | 挑剔工艺、闲话毁誉 | 仪轨怎么走、旧愿欠谁 |
| 邻里中介（如陈婶） | 介绍单、抬镇民信任 | 偶尔托你瞒家里人的小阴事 |
| 同行（对门香火店等） | 抢单压价 | 甩锅、共背、脏料渠道【香火店是否常驻见第2.6节】 |
| 「那侧」与夜口碑 | 几乎不公开 | 老人认可、同行忌惮、纸马童引荐 |

人情在规则里可有抽象池，但玩家记得住的是具名：叫柳裁缝来、让陈婶圆场、支书盖一次章。

#### 2.2.3 日与夜：同一张脸两套账

太阳底下，纸扎铺是合法民俗生意：红白纸货、安神符、搬家净宅、寻物、阳面送行。交期、彩头、能不能拍照——规矩轻，反馈快。

天一黑，账本翻到夜页。同一间铺、同一批材料，换一本规则书：送行要送到「那边认账」、安魂要分清真假客、两套账要补阴面条件、纸人自行要善后。报酬更高，禁忌更重；偶发高压挂在履约现场。

| 白天玩家看见 | 夜里玩家看见 | 世界在说什么 |
| --- | --- | --- |
| 反封建通知、合规净宅 | 便装塞红包、按老规矩办 | 权力也怕立案 |
| 要拍摄、要好看 | 求删图、求安神 | 镜头会把不该看见的留住 |
| 热心红白事 | 托你别跟家里人说 | 温情里也有小阴事 |
| 把符当安慰剂认真收钱 | 拒诊「病人」转到夜里那本账 | 科学口吻与装瞎可共存 |
| 纸马旁像摆设的「童」 | 接待、带路、引夜里的单 | 铺子里谁算活人——持续疑问 |

**阳间生意**：维持正常铺面人设；攒钱、料、洁净、镇民信任；为夜里买门票。  
**诡异生意**：私下履约；涨夜口碑；搞砸外溢次日阳间。拒单也有代价：有些单「被盯」，不理它会记你一笔。

日接夜交（`bridge`）：白天可收订金、开阳面合同；夜里才办真阴事。出现频率与是否和「被盯」同类——见第2.6节【暂定】。

#### 2.2.4 规矩、禁忌、阴气、洁净（世界理解）

**规矩**：办阴事时事情肯不肯认账的手续。阳间轻忌像乡俗；夜页重忌像真规则书。可知条目接单可见；隐藏条目要打听或履约中途才翻出——**不知比硬闯更致命**。

规矩分档（玩家体感）：

| 档 | 世界说法 | 玩家感到 |
| --- | --- | --- |
| 歪办 | 总能糊弄，邪门 | 能压一点局面，易惹阴气 |
| 正统 | 洁净够、老人教过 | 履约时像样地压局面 |
| 老人认可 | 夜口碑到了一定份上 | 特定事少踩隐忌或再轻一档 |

禁忌来源三层：民俗层（黄历、属相、方位）；行业层（纸扎/送行/安魂交法）；现场层（这单特有条件）。隐藏忌多半在现场层。

**阴气**：不是血条，是「铺子与街上不对劲的浓度」。灯色发冷、纸灰微扬、日客台词发虚、夜里的单变密变凶。守规矩成功履约可降一点；抬起来的常见原因：夜错规矩、脏料硬上、拒被盯、履约失败。

紧张态叙事说法【示例】：阴气偏高 → 镇子发虚；再高 → 街上炸锅；顶到头 → 坏结局检定之一。玩家应感到街上在议论你，而不是 HUD 数字在尖叫。

**洁净**：料与铺的清气；夜里走正统仪轨的门票。赶工、脏料、糊弄磨薄洁净。洁净仪轨叙事上是「把铺子擦回能见人」，也可参与清除更重的「不对劲」标记（清除条件【暂定】，见第2.6节）。

**履约现场**：玩家支付规矩、道具、人情，把局面压下去，完成送达/封门/安座等主目标。可压下（留把柄）、可跑路。多数夜里的单可算计；顶格夜【示例】每隔若干游戏日至多一回——选项更少、文案更静、失败伤经营更重。履约主流程结构【暂定】见第2.6节。

#### 2.2.5 纸扎行业、纸马童、信物（叙事位）

纸扎铺夹在阳间仪式服务与阴事中介之间：不是除魔公司，是小镇刚需的灰色基础设施。

纸马童：白天几乎不主动说话；夜里接待、带路、引荐夜里的单。通关前规则定位是**引荐 + 带路**，不做战斗宠。终局解释【暂定】：旧愿 / 非人看门 / 长辈错身——未拍板前文案保持模糊，不提前剧透。

信物：办成难事留下的物件；叙事优先于数值。效果宜省一次心、多一句提示、轻一点惩罚。上限/是否挡封门/是否继承——见第2.6节【暂定】。

#### 2.2.6 双口碑、被盯、坏结局（世界含义）

| | 镇民信任（阳） | 夜口碑（阴） |
| --- | --- | --- |
| 世界含义 | 还是不是正经铺；陈婶还介绍不介绍 | 老人认不认；夜里还有没有稳妥单 |
| 涨 | 阳交货漂亮、公开圆场 | 诡履约成功、守密、柳点头 |
| 跌 | 夜事外溢、短视频传闻、日间抽查 | 拒被盯、泄夜密、跑路 |

「被盯」：有的夜里的单不理也会记你。可以花钱洗把柄【示例】——世界说法像疏通，不是无敌护盾。频率与洗次数【暂定】。

「不对劲」：比普通失败更沉的叙事标记。坏结局不是 Game Over 跳脸，是短过场（易主/离开小镇）；可读档回上一日日初。普通失败白天能补——经营感靠「还能补」托住；高压靠顶格与街上炸锅偶发。

### 2.3 术语与字段字典

#### 2.3.1 易混术语组

| 术语组 | 区分口径 |
| --- | --- |
| 游戏日 / 白天 / 夜里 | 游戏日=完整一天（旧称镇日）；白天=阳间营业段（旧称日档）；夜里=诡接单+履约+收摊（旧称夜档） |
| 阳间生意 / 诡异生意 | 日公开民俗单 vs 夜私下阴事单；不是「白天赚钱夜里只挨打」 |
| 镇民信任 Ty / 夜口碑 Tn | 两行口碑，禁止合成单一好感 |
| 阴气 H / 洁净 C | H 越低越好（不对劲浓度）；C 是正统仪轨门票 |
| 人情 F / 具名人情卡 | F 抽象池；卡是「叫谁来」的具名消耗 |
| 轻忌 / 重忌 | 阳彩头级 vs 夜规则书级 |
| 可知禁忌 / 隐藏禁忌 | 接单可见 vs 打听或履约中揭示 |
| 局面 Threat | 履约现场要压下去的值；不是玩家血条 |
| 歪办 / 正统 / 老人认可 | 仪轨三档 |
| 日接夜交 / 被盯 | 日接夜交（叙述名；配置字段仍为 `bridge`）vs 不理也记账的夜里的单压力（关系【暂定】；事件专项已锁：日接夜交默认不计被盯） |
| 压下 / 跑路 / 失败 | 履约三种非胜利终态 |
| 不对劲 | 叙事重标记；非普通失败同义 |
| 纸马童 | 引荐带路 NPC；非战斗宠、非普通伙计 |

## 3. 核心流程

### 3.1 玩家感受与决策取舍（先读这段）

一个游戏日里，玩家反复做同一类经营决策，但日夜规则书不同：

| 时段 | 玩家在做什么 | 主要感到 | 关键取舍 |
| --- | --- | --- | --- |
| 白天 | 接白天的单、备料工艺、交货、进货、打听、稳住伙计与人情 | 稳、公开、冷幽默多在柜台圆场 | 精工攒洁净 vs 赶工省交期；花钱进洁净料 vs 省钱碰脏料；拒关键介绍单的轻罚 |
| 落锁 | 账本翻夜页；日末结算 | 「你以为加班做纸人」 | 未交白天的单是否认失败硬落锁 |
| 夜里接单 | 看夜里待接栏与日接夜交待办；接/拒/加价 | 报酬高、规矩狠 | 少接降压 vs 拒被盯留把柄；加价换 risk |
| 夜履约 | 短现场压 Threat；完成主目标 | 偶发高压；生存辅循环在此 | 规矩/道具/人情怎么配；压下留把柄 vs 跑路伤口碑 vs 硬撑 |
| 收摊 | 夜末写回；具名后果进次日 | 夜里搞砸，白天客少伙计怯 | 次日用经营补救，还是硬扛再接夜里的单 |

日夜互相拖累或救命：白日做稳 → 夜里更敢接；夜里的单搞砸 → 伙计怕、白天客少、铺面被议论。

### 3.2 游戏日状态机

| 状态 | 开始条件 | 页面表现 | 结束条件 |
| --- | --- | --- | --- |
| `BOOT` | 启动 | Logo/版权 | 进主菜单 |
| `MAIN_MENU` | 启动完成或回标题 | 继续/新局/读档/设置 | 开新局或读档成功 |
| `DAY_SHOP` | 日初或读档落入白天 | 柜台默认；HUD 日态 | 落锁确认 |
| `DAY_TO_NIGHT` | 落锁 | 翻夜页仪式 + 日末结算摘要 | 结算完成 |
| `NIGHT_BOARD` | 日末结算后 | 夜接单；日接夜交置顶 | 进履约或收摊检通过 |
| `NIGHT_FULFILL` | 赴约 | 履约现场；禁存 | 胜/败/压下/跑路结算 |
| `NIGHT_TO_DAY` | 收摊 | 夜末结算 + 口碑动画 | 坏结局检后进日初或 `BAD_END` |

| `PAUSE` | 任意合法壳上开菜单 | 设置/存读档（受禁存） | 关闭 |

| 编号 | 阶段 | 触发条件 | 核心结果 | 规则来源 |
| --- | --- | --- | --- | --- |
| 1 | 开局/读档 | 新局或选合法档 | 落入 `DAY_SHOP` 或标记的合法壳；不落入履约中途 | 第2.5、4.1、4.11 节 |

### 3.4 白天：阳间生意（流程摘要）

```
日初刷新白天的单 → 接/拒/议价 → 备料（普通|赶工|精工；正料|替代）→ 交货检轻忌 → 结算
并行铺务：进货、打听、送礼/安抚、洁净仪轨（若开放）
→ 落锁
```

| 步骤 | 条件 | 系统行为 | 结果 |
| --- | --- | --- | --- |
| 刷新 | 每游戏日日初 | 按 Ty 与镇上熟人加权抽样 | 白天的单列表生成；剧情强制单先插入 |
| 接单 | 玩家确认接 | 锁定预计 need_S；不足标替代意向；耗日限次【暂定·AP 见第2.6】 | 单进待办 |
| 拒单 | 一般脸 | 无惩罚关单 | — |
| 拒单 | 陈婶/支书关键介绍 | 轻罚【示例】Ty-1 或下次少 1 单 | 确认框列出后果 |
| 议价 | 每单至多 1 次 | 成功则 +10%～20% 报酬或换长交期【示例】 | 失败可记轻忌 |
| 备料 | 待备料 | 按工艺模式扣 S/C 或记 day_offense | 成品待交货 |
| 交货成功 | 轻忌通过 | M+pay；Ty+1（首次帮某脸 +2）【示例】 | 精工可额外 Ty+1 |
| 交货失败/严重犯规 | 检定失败 | M 无；Ty-2；轻忌仍入日末【示例】 | — |
| 日接夜交白天侧 | 单标日接夜交 | 收订金【示例】30%～50% pay_base | 夜强制履阴面 |

阳间轻忌：犯规 `day_offense += 1`；日末 `H += min(2, day_offense)`【示例】。尺度：丢钱丢信任为主，不轻易拉满阴气。

### 3.5 夜里：诡异生意（流程摘要）

```
落锁后刷新夜里待接栏（含日接夜交置顶）→ 接/拒/加价 → 可选连夜备阴 → 履约现场 → 单笔结算
→ 全部待办终态 → 收摊 → 夜末总结算 → 坏结局检 → 次日
```

| 步骤 | 条件 | 系统行为 | 结果 |
| --- | --- | --- | --- |
| 刷新 | 落锁后 | 受 Tn、H、角色加权 | 基础 1 张；Tn≥5 可 2；H≥12 强制 ≥1「被盯」【示例】 |
| 顶格标记 | 排期条件 | 每 3～5 游戏日 ≤1【示例】；节气可强制 | 选项更少、文案更静 |
| 拒普通夜里的单 | 非被盯 | 可拒 | Tn 不涨 |
| 拒被盯 | 玩家确认 | H+1；留把柄【暂定天数见第2.6】 | — |
| 接单 | 确认 | 锁 need_S；不足自动替代料 | 可赴约 |
| 履约胜利 | Threat≤0 且主目标完成 | 按普通/顶格成功写回 | 可能信物 |
| 压下 | 付双倍人情或指定代价 | 强制 Threat=0 | 半报酬；把柄 |
| 失败/跑路 | 回合或选项耗尽 / 选跑路 | 失败写回；跑路另 Tn-1 | 具名后果 |

生存辅循环：**只在履约现场**用规矩/道具/人情压局面。经营选择（少接、只做日接夜交尾巴）本身是合法降压。

履约结构【暂定】：推荐回合制（见第2.6节）；正文第4.4节按推荐倾向写清条件—行为—结果，并保留三槽备选对照，避免程序只实现一套却误标已锁定。

### 3.6 日夜结算顺序（总线）

**日末 → 夜初（落锁时，顺序不可打乱）：**

1. `H := H + min(2, day_offense)`【示例】  
2. 已接未履 `bridge` 推入夜里那本账待办；不另加 H  
3. `S`、`C` 原样带入夜里  
4. 清空 `day_offense`  
5. 生成夜里的单池  
6. 应用延迟到落锁的具名标记  

**夜末 → 次日日初：**

对每一笔已结算夜里的单按结果类型写回，再全局收尾（clamp → 持续标记日数-1 → 坏结局检 → 否则日初刷新白天的单）。

| 结果类型 | 写回【示例】 |
| --- | --- |
| 成功（普通） | M+；H-1（下限 0）；Tn+1 |
| 成功（顶格） | 同上 + Tn+2；可能信物 |
| 压下 | M 半报酬；H 不变或 +1（按单配置）；把柄 |
| 失败（普通） | M 无或少；H+2；Ty-1；N-2；1 个具名议论 |
| 失败（顶格） | H+4；Ty-3；N-4；可能贴条/封门 1 日 |
| 拒接所有夜里的单 | H+0；Tn 不涨；有被盯未处理则 H+1 |
| 跑路 | 普通失败 + Tn-1；目击者脸 → 具名后果 |

相对大小（平衡前只锁）：夜报酬 > 阳报酬；顶格创伤 > 普通夜；白天补救总成本 < 一次顶格失败创伤。

报酬带【示例】：普通夜里的单 40～90；顶格 100～160；白天的单 15～45。

## 4. 阶段 / 功能细节

> 覆盖旧 modules 01～11 与 00a 能力。每块含：玩家场景、开放条件、入口、核心循环、失败恢复；UI 保留可读级要点。限次、履约结构等引用第2.6节【暂定】，不在本节锁死。

### 4.1 时间、会话与壳层

**玩家场景**：感到一个游戏日两段生意；时间紧时「只够办几件大事」。

**开放条件**：新局过场结束或读档落入合法壳即开放。

**入口**：主菜单 → 继续/新局/读档；白天默认柜台；下入口条切换订单/账本/街巷/伙计/菜单。

**核心循环：**

| 单位 | 定义 | 边界 |
| --- | --- | --- |
| 游戏日 | 白天 + 夜里 | 一周目主线基准 = 15 个游戏日可通【示例】；旁支/复玩可 ±2～5【示例】 |
| 白天 | 阳间营业动作集合 | 手感 10～18 min |
| 夜里 | 诡接单 + 履约 + 收摊 | 5～12 min |
| 节气/庙会日 | 特殊游戏日标签 | 默认落在 D10（`season_tag=temple_fair`）；D9 预告、D11 余波；可强制顶格候选或改权重 |

**白天限次【暂定·推荐混合制】：**

| 规则（推荐倾向） | 内容 |
| --- | --- |
| 白天 AP 总量 | 【示例】6；每日日初重置 |
| 接谈链 | 1 AP/次；交货并入接谈链不另扣 |
| 备料/工艺 | 1 AP/批次 |
| 铺务（修铺/安抚/送礼） | 1 AP |
| 打听 | 1 AP |
| 进货 | 单独 1 AP（推荐；备选并入铺务） |
| 挂钟三段 | 午前/午后/傍晚：氛围 + 时段解锁/催落锁软约束；**不**单独扣重大决策次数 |
| 夜里 | 不耗白天 AP |

备选对照：纯 AP（无挂钟决策意义）；纯时段（每段 1～2 次重大决策，无 AP 条）。拍板前程序实现以推荐倾向为唯一主 UI，备选不进主路径控件。

**切换说明：** 若拍板为纯时段，则凡正文写「耗 1 AP」之处改为「消耗当前时段 1 次重大决策次数」；HUD 隐藏 AP 条、强化时段格。若拍板为纯 AP，则挂钟仅装饰，去掉时段解锁软约束。第6章字段 `ap_*` / `period` 随拍板裁剪，不两套同时生效。

**落锁：**

1. 玩家点「落锁营业」或傍晚强制。  
2. 若有逾期未交白天的单 → 二次确认「未交货将失败结算」。  
3. 进入日末结算（第3.6节）→ 夜接单；推荐自动存于夜接单点。

**收摊：**

1. 已接夜里的单须有履约终态；日接夜交未履约视同普通夜失败。  
2. 夜末结算 → 坏结局检 → 次日日初或 `BAD_END`。

**存档：** 见第2.5节。履约中存档按钮灰 + toast「履约中不能存档；读档会回夜接单」。

**UI 要点：** HUD 显示日夜态、时段、AP（若用混合/纯 AP）、M/S、C/H 淡条、Ty/Tn 分行、紧张态灯；夜履约收起街巷；通用灰显气泡 `现在不行：{reason}`。

**失败恢复：** 崩溃回最近合法档；夜现场退出回接单；坏档修正到日初或夜接单。

**常见 reason 对照名：** `no_AP` / `period_locked` / `save_forbidden_fulfill` / `nerve_refuse_night` / `dirty_rite_locked` / `need_S_short` / `story_lock`。

### 4.2 资源与日夜结算

**玩家场景**：钱料是账本上的数；洁净阴气靠气味与街谈；落锁/收摊有清楚摘要。

**开放条件：** 随会话常驻。

**入口：** HUD 摘要；账本日/夜页；落锁/收摊仪式内嵌结算卡；紧张态灯点开说明。

**核心循环：** 资源定义见第2.3.2节；结算顺序见第3.6节；紧张态见第3.8节。

| 呈现约束 | 规则 |
| --- | --- |
| M/S | 账本数字 |
| C/H | 环境为主，账本可淡色条 |
| Ty/Tn | 两行，禁止合成单一好感 |
| F | 抽象池 + 具名卡列表 |

**失败恢复：** 结算中允许开设置；存档受第2.5节边界；触顶 toast「堆不下」；结算摘要不可改数。

### 4.3 阳间订单与工艺

**玩家场景**：白天柜台接单议价备料交货；反馈快；料留给夜里用。

**开放条件：** 白天 `DAY_SHOP`；教学 D1 起开放白天的单。

**入口：** 柜台订单条 / 「订单」入口 → 白天的单列表 → 接谈弹层。

**核心循环：**

```
午前刷新 → 接/拒/议价 → 备料 → 交货 → 结算
```

| 阶段 | 条件/规则 | 边界 |
| --- | --- | --- |
| 刷新数量 | 受 Ty【示例】0–6：2 单；7–13：3；14+：4 | 剧情强制单可单列 |
| 接单 | 锁 need_S；不足标替代意向 | 交期进待办 |
| 拒单 | 见第3.4节 | 关键脸轻罚 |
| 议价 | 每单至多 1 次 | 成功报酬或交期二选一 |
| 逾期 | 交期到未交货 | 失败；可求情延期 1 次耗 F【示例】 |

**工艺：**

| 模式 | 支付 | 效果【示例】 |
| --- | --- | --- |
| 普通 | need_S；满足 need_C 则洁净档 | 默认 |
| 赶工 | -1C **或** day_offense+1 | 省 1 档交期；最短交期不可再赶 |
| 精工 | 额外 -S【示例】+2；成功 C+1 | 交货 Ty 额外 +1 |
| 替代料 | proxy/dirty | 阳或掉 Ty；转夜抬 Threat |

**阳间轻忌示例：**

| code | when | 描述 | break_cost【示例】 |
| --- | --- | --- | --- |
| `no_joke_funeral` | 交货 | 白事勿笑场 | day_offense+1；严重 Ty-1 |
| `no_flash` | 接谈/交货 | 勿让阿杰闪光灯拍成品 | day_offense+1；传播挂阿杰线 |
| `zodiac_block_white` | 交货 | 属相日不交白事 | 改期或 day_offense+1 |
| `no_dead_bargain` | 议价 | 勿讲价讲死气 | 议价失败 + day_offense+1 |

**日接夜交白天侧【暂定·推荐】：** 订金 30%～50%；重要剧情脸每 2～3 游戏日 ≤1 张；夜强制履约见第4.4节。

**样例单【示例】：**

- 阳·陈婶介绍白事纸扎：`pay_base=28`；`due=次日`；`need_S=4`；轻忌勿笑场；成功 Ty+2（陈婶线）。  
- 阳·吴支书合规净宅：`pay_base=35`；`need_S=3`；`need_C=1`；可勾 日接夜交。

**UI 要点：** 列表显示脸、报酬、交期、risk、日接夜交角标；接谈左立绘右单卡；工艺屏材料槽与模式三选；交货轻忌危险选项强警告。

**失败恢复：** AP/限次不足灰显；精工 S 不足灰；逾期走失败或求情；替代料须确认「将使用替代料意向」。

### 4.4 夜里那本账订单与履约现场

**玩家场景：** 夜里另一本账；多数单可算计；顶格才真正静下来高压。

**开放条件：** 落锁进入 `NIGHT_BOARD`；教学 D1 可接 1 张低 risk（可拒）。

**入口：** 夜里的单列表；日接夜交置顶；赴约进 `NIGHT_FULFILL`。

**核心循环：** 见第3.5节。

**被盯与把柄【暂定·推荐】：** 拒被盯 → H+1 + 把柄约 3 游戏日；可花钱洗 1 次/周【示例】（白天铺务或账本入口）。

**Threat 初值【示例】：**

```text
Threat0 = risk + clamp(H/6, 0, 2) + (替代料 ? 1 : 0) + (顶格 ? 2 : 0)
```

再 clamp 到 1～5【示例】。

**履约手段（三件套）：**

| 手段 | 支付 | 效果【示例】 | 错选/不可用 |
| --- | --- | --- | --- |
| 规矩 | 已解锁仪轨；可耗 C | Threat-2 | Threat+1 且 H+1；顶格加倍 |
| 道具 | 预做符/成品/S | Threat-1；脏料同 -1 但 H+1 | 无道具不可选 |
| 人情 | F 或具名卡 | Threat-2；卡带特殊解 | 无卡花 2F → 仅 Threat-1 |

**结构【暂定】对照：**

| 方案 | 玩法 | 推荐 |
| --- | --- | --- |
| 回合制 | 每回合选 1 手段；普通最多 4 回合、顶格 3【示例】；直至胜/败/压下/跑路 | 推荐倾向；主 UI 按此写 |
| 一次性三槽 | 一次为规矩/道具/人情各摆一档后结算 Threat；胜负/压下/跑路判定与回合制相同（Threat≤0 且主目标完成等） | 备选；不与回合制同时进主 UI |

**终态判定：**

- 胜利：Threat≤0 且主目标完成。  
- 压下：双倍人情或指定具名代价，强制 Threat=0，走压下结算。  
- 失败：Threat 仍高且回合/选项耗尽。  
- 跑路：普通失败 + Tn-1；目击者脸 → 具名后果。

**检定顺序：** 进现场 → 揭示未打听 hidden → 选手段 → 主目标检 → 结算。

**顶格夜：** 频率 3～5 游戏日 ≤1【示例】；少 1 通用手段；错规矩惩罚加倍；冷幽默收束关闭；优先消耗柳卡。

**样例【示例】：** 诡·吴便装安魂 `pay_base=70` risk=2；诡·阿杰删图安神 `pay_base=90` risk=3（可顶格候选）。

**UI 要点：** 上 Threat 条；中主目标与已知禁忌；下三件套与回合数（若回合制）；跑路/压下二次确认；现场禁存。

**失败恢复：** 单笔结算后回夜接单继续其他待办；收摊前须清待办；洗把柄超周次灰显。

### 4.5 禁忌、阴气与洁净

**玩家场景：** 阳忌像彩头；夜忌像规则书；不知更致命；脏铺只剩歪办。

**开放条件：** 随订单与履约；仪轨正统档约 D3 柳传授后（教学编排）。

**入口：** 接单禁忌条；账本夜页笔记；履约规矩列表；铺务洁净仪轨。

**禁忌字段：**

| 字段 | 说明 |
| --- | --- |
| `code` | 如 no_photo / month_block / no_third / no_record / true_name |
| `realm` | yang \| yin \| both |
| `severity` | light \| heavy |
| `when` | accept / craft / fulfill |
| `visible` | known \| hidden |
| `break_cost` | H+、锁选项、结局支、具名标记 |
| `hint` | 外乡可见短提示 |

**可知 vs 隐藏：** 可知接单列出；隐藏履约中揭示，或白天打听提前揭 1 条。

**阴气 H 来源【示例】：** 日末轻忌累计；夜错规矩；脏料道具；拒被盯；夜失败 +2/+4；成功履约 -1（下限 0）。上界 20。**不做：** 白天正常经营把 H 当主惩罚。

**洁净 C：** 精工 +1；林医生洁净料；赶工 -1；规矩可耗 C。脏铺 C<4 → 正统锁定。

**仪轨档：**

| 档 | 解锁【示例】 | 效果 |
| --- | --- | --- |
| 歪办 | 默认 | 弱规矩或附带 H+ |
| 正统 | C≥4 且柳已教第 1 条 | Threat-2 |
| 老人认可 | Tn≥5 / ≥10 | 特定 tags 额外 -1 或免隐忌一次 |

**洁净仪轨（与「不对劲」清除咬合）【暂定】：** 白天铺务，耗 C 与 AP（或指定材料）；成功记 `cleansing_done`；可微降 H【示例】H-1。清除不对劲的完整条件见第4.6节与第2.6节。

**尺度：** 发忌/错身/纸人自行；避免过度血腥与宗教照搬。黄历全局修正【暂定建议】默认只叙事。

**失败恢复：** 脏铺时正统全灰并给 reason；顶格错选双倍反馈播完再续；打听入口在夜履约中不开放（叫柳卡除外）。

### 4.6 失败、口碑与结局

**玩家场景：** 失败变成「谁在议论你」；普通失败白天能补；坏结局短、可读档。

**开放条件：** 随结算；补救菜单在存在可补救标记的次日日初提示。

**入口：** 结算卡具名后果行；`UI_Remedy`；`UI_BadEnd`；不对劲 HUD 符；封门贴条叠层。

**双口碑：** 见第2.2.6节；交叉——夜失败常双跌；揭穿吴：Ty+2 但 Tn-3、吴退夜里待接栏【示例】。

**具名后果【示例】：**

| 触发 | 后果 |
| --- | --- |
| 夜失败 × 阿杰 | 镇群传闻；次日阳刷新 -1 |
| 夜失败 × 吴 | 日间抽查；强制低价白天的单 |
| 夜失败 × 伙计在场 | N-3；拒夜台词 |
| N≤2 | 不可带伙计履约；产能 -1 |
| Ty≤2 | 陈婶暂停介绍 |
| Ty=0 | 【暂定·推荐】先假死一晚（次日糊口小单/强提示），再并入破产检 |
| 顶格失败 | 贴条/封门 1 日 |
| H≥18 连续 2 夜 | 进入坏结局检定 |

**坏结局门槛【示例】【暂定力度】：** 任一条：

1. `H≥20`  
2. `Ty=0` 且 `Tn=0` 且 `M=0` 且 `S=0`（经 Ty=0 假死流程后仍满足）  
3. 顶格失败且已有「不对劲」标记  

流程：短过场（易主/离开）→ 「回到上一日日初」。

**「不对劲」【暂定·推荐】：**

| | 内容 |
| --- | --- |
| 获得 | 顶格失败；或 H≥18 曾持续一晚后挂上 |
| 清除 | 连续 2 个无顶格失败的游戏日 + 做 1 次洁净仪轨 |

**补救菜单（经营感）：**

| 补救 | 效果【示例】 |
| --- | --- |
| 低价白天的单 ×2 | 回 M |
| 送礼 | 回 F |
| 精工 | 回 C |
| 主动低 risk 夜里的单 | 回 Tn |

固定入口句：「白天还能补」。补救总成本 < 一次顶格失败创伤。

**失败恢复：** 封门日高价白天的单灰或少单；不对劲未清又顶格失败 → 坏结局；不提供现场重来。

### 4.7 角色、人情与伙计

**开放条件：** 常驻脸按教学排期出场；人情卡按线进度获得。

**入口：** 柜台立位；街巷点；人情卡列表；伙计面板；日间揭穿/拿捏选项（吴）。

| 纸马童 ★ | 几乎不说话；递错东西 | 接待/带路；童引单 | 终局【暂定】见第2.6节；通关前只引荐+带路 |

### 4.8 进货与材料

**玩家场景：** 白天进的料夜里真能用；缺料可替代但更险；紧巴时进货本身是压强。

**开放条件：** 白天；认识林/柳后开对应源；香火店随第2.6节【暂定】。

**核心循环：**

| 规则（推荐倾向） | 内容 |
| --- | --- |
| 时机 | 白天；扣 1 AP/次【暂定·随混合制】 |
| 次数 | 【示例】每游戏日最多 2 次 |
| 支付 | M；可能耗人情托带 |

| 源 | 卖什么 | 备注 |
| --- | --- | --- |
| 镇集/杂货 | 普通 S | 价低；不涨 C |
| 林医生 | 洁净料包 | M→S+ 且 C+1 |
| 柳旧渠 | 稀有符胚 | 欠愿或 F |
| 香火店 | 便宜 S，偶发脏标签 | 仅当常驻开启【暂定】 |
| 夜临时 | 一般不开放大宗 | 可雇护法花 M |

**价目【示例】：** 普通小捆 10M→+4S；大捆 22M→+10S；洁净料包 18M→+3S且C+1；符胚 12M；香火店特价捆 8M→+5S（概率 dirty）。

**不做：** 大地图采集；夜战场掉大宗纸料；复杂合成树（符胚首周目 ≤5【示例】）。

**失败恢复：** AP/次数不足灰；M 不足灰；香火店特价二次确认脏风险；堆不下 toast。

### 4.9 打听情报

**玩家场景：** 外乡花钱花面子换少踩雷；信息差即难度。

**开放条件：** 白天；教程后账本旧注默认；认识对应脸后开渠道。

**入口：** 街巷/订单「打听」；订单卡「？」捷径。

**核心循环：**

| 规则 | 内容 |
| --- | --- |
| 时段 | 仅白天；夜履约中不开放查攻略式打听 |
| 成本 | 【示例】1 AP + 可选 F（柳等要面子渠道） |
| 次数 | 【示例】每游戏日最多 2 次 |
| 目标 | 已刷新未履约单 / 常驻脸 / 禁忌主题 |
| 单次产出 | 默认 1 条有效情报 |

### 4.10 信物与永久小加成

**玩家场景：** 办成难事留下的物件；省一次心，不是装备膨胀。

**开放条件：** 顶格成功或角色线节点；教学窗内不宜早于首次顶格或 D5+。

**入口：** 获得弹层；账本信物页；生效栏最多展示上限件数。

**规则【暂定·推荐】：**

| 项 | 内容 |
| --- | --- |
| 同时生效上限 | 3；超出进仓库仅叙事 |
| 挡封门 | 不挡 |
| 新周目 | 默认不继承；可留 1 件叙事物为备选 |
| 购买 | 现金不买永久信物 |
| 履约中 | 只读，不可换装 |

**获得【示例】：** 顶格成功 50% 或前 2 次保底；普通夜默认不掉；角色线 0～1。

**效果约束：** 优先改信息、次数、惩罚减免、刷新微权重；少改报酬倍率。

**示例信物：** 旧账铜扣（每日首次打听不耗 AP）；柳指顶针（每游戏日第一次错规矩免 H+1，Threat 仍+）；支书空烟盒；纸马蹄铁；陈婶保温袋扣；静符残角；净瓶塞。

**失败恢复：** 生效已满 3 时强制选择替换或进仓库；无买信物入口。

### 7.1 主路径验收要点

| 用例 ID | 分类 | 前置条件 | 操作 | 通过标准 |

| QA-02 | 主路径 | D2 | 完成吴日间白天的单与夜里便装遇 | 玩家可辨同一人错位；守密默认可继续 |

| QA-08 | 教学 | 首周目 | 强制步仅可点焦点 | 超时不自动跳过强制步；复玩可跳 UI 说明 |
