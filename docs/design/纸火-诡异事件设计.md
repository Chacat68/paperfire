## 1. 概述

### 1.1 设计目的

本专项回答：在《纸火》已拍板的「白天阳间生意、晚上诡异生意；经营为主、生存为辅」框架下，**诡异感从哪里来、何时来、玩家怎么选、选完怎么回到经营**。

要解决的具体问题：

1. 诡异内容如何分类，才能让冷幽默占主、高压偶发，而不是全程绷紧或全程玩笑。
2. 触发如何绑在订单、禁忌、Threat、阴气、双口碑、天数、道具、角色关系上，让玩家感到「是我招的 / 我早该看见」，而不是「系统乱掷骰」。
3. 单次事件如何走完「预兆→遭遇→决策→结算→余波」，失败砸铺子与人，白天还能补。
4. 如何与规矩、禁忌、承诺链（把柄/欠愿/守密等）、香火店【暂定】、双账本、日夜人物咬合，且玩家看得见反馈。

成功标准（可读优先）：

- 读完第1～3章，能复述：诡异事件挂在哪条主路径上、绝不另开什么。
- 读完第4章任一类，能按「触发→选项→代价/回报→余波」写出一条可配事件。
- 未拍板项见附录 A「待拍板」；已拍板见附录 A「已拍板（本版）」。正文不把仍【暂定】的项写成铁律。

### 1.3 一句话定位

诡异事件 = **订单与人物关系上长出来的短决策内容**；多数在夜履约现场与日夜错位遭遇里完成，少数以「次日外溢余波」或「白天柜台冷幽默」形式出现。玩家付的是规矩、料、人情与口碑，不是血条。

## 2. 设计 & 通用规范

### 2.1 核心理念（事件层）

| 已对齐 V0.3 的原则 | 事件层落地 |
| --- | --- |
| 经营主、生存辅 | 事件消耗经营资源；高压偶发；多数失败次日可补 |
| 诡异来自接不接、怎么交差、知不知规矩 | 触发绑订单/禁忌/打听结果；不知比硬闯更致命 |
| 人驱动 | 重要事件绑常驻脸；一次性脸只补量 |
| 少血腥、发忌/盯梢/错身/纸人自行 | 文案与结算优先这些形态；禁止血浆追逐战 |
| 不做被动挨事件时段 | 无独立「闹鬼阶段」状态；紧张态不另开操作循环。无订单宿主的高压事件**允许**，但计入日随机配额（见第2.3.4节） |

设计取舍（影响后续规则）：

- **可算计优先于惊吓**：玩家应能从预兆、禁忌条、镇子发虚的灯、纸马童半句话预判「今晚大概什么味」。
- **余波经营化**：夜事搞砸 → 次日客少、抽查、伙计怯；补救菜单承接（见 V0.3 第4.6节）。
- **无单一最优解**：选项在「稳但亏 / 险但赚 / 留把柄换过关」之间互咬；不同资源状态最优不同。

### 2.2 事件分类体系（全文唯一分类口径）

分类按**玩家主要感到什么**划分，不按程序实现模块名划分。一条实例可打多个标签，但主类唯一。

| 主类 ID | 名称 | 玩家感受目标 | 冷幽默 : 高压【示例占比】 | 典型例子（2～3） |
| --- | --- | --- | --- | --- |
| E-FACE | 日夜错位遭遇 | 「同一个人，白天那样夜里这样」 | 7 : 3 | 吴支书便装塞红包；林医生拒诊转介；陈婶托你别跟家里人说 |
| E-FULFILL | 履约现场发忌 | 短现场压局面；不知规矩比怕更致命 | 4 : 6（顶格 1 : 9） | 纸人自行要善后；送行错身；第三人在场发忌 |
| E-WATCH | 被盯与把柄 | 「不理它也记你一笔」 | 3 : 7 | 拒被盯留把柄；花钱洗把柄像疏通；把柄到期变凶单 |
| E-BRIDGE | 日接夜交翻转 | 阳面合同夜里变真阴事 | 6 : 4 | 白天「净宅宣传」夜安魂；订金已收必须履 |
| E-SPILL | 次日外溢余波 | 夜里搞砸，白天街上在议论 | 5 : 5 | 阿杰短视频传闻；封门贴条；伙计拒夜班 |
| E-TONG | 纸马童相关 | 铺里谁算活人——持续疑问 | 6 : 4 | 童引单；递错东西；带路跳过错身检 |
| E-INCENSE | 香火店相关（常驻开启时才进池） | 同行甩锅、脏料便宜 | 5 : 5 | 特价脏料二次确认；共背一单；压价抢白天的单（阳间订单） |
| E-TENSION | 紧张态显现 | 街上不对劲，不是数字尖叫 | 4 : 6 | 镇子发虚：日客台词发虚；街上炸锅（紧张态顶档的玩家说法）强制顶格候选；洁净仪轨擦铺 |
| E-OATH | 承诺链兑现（把柄/欠愿/守密/旧愿） | 「你答应过的，现在到点了」 | 3 : 7 | 柳欠愿催仪轨债；吴守密勒索日接夜交；旧愿相关【暂定】 |

> **说明：** E-INCENSE **仅常驻才进池，否则整类权重归零**（已拍板，随 V0.3 B5）。示例库对应条目标「条件：常驻开启」。E-OATH 不新增独立系统，只编排既有标记的到期与催讨（见第2.7节）。

### 2.3 触发规范（全文唯一）

#### 2.3.1 触发维度

| 维度 | 读什么 | 典型用法 |
| --- | --- | --- |
| 昼夜 / 壳状态 | `phase` / `shell_state` | 错位多在夜接单或履约；外溢多在次日 `DAY_SHOP` |
| 订单 | `realm` / `tags` / `risk` / `peak_flag` / `watched_flag` | 履约类挂单；日接夜交（`bridge`）置顶 |
| 禁忌 | `taboos[]` / `visible` | 隐忌未打听 → 履约中揭示事件 |
| Threat | `threat` / `threat0` | 局面过高触发「压下/跑路」岔路文案包 |
| 阴气 / 洁净 | `H` / `C` | 镇子发虚/街上炸锅/脏铺改权重与可选手段 |
| 双口碑 | `Ty` / `Tn` | 夜里待接栏（接单列表）张数、介绍单、老人认可档 |
| 天数 / 节气 | `town_day` / `season_tag` | 教学窗禁顶格；庙会可强制顶格候选 |
| 道具 / 料 | `proxy_flag` / dirty / 信物 | 替代料抬 Threat；脏料道具事件 |
| 角色关系 | 脸进度、`wu_secret`、人情卡、童信任 | 错位、守密、童引 |

#### 2.3.2 必然 / 概率 / 主动招惹

| 类型 | 定义 | 玩家应感到 | 【示例】 |
| --- | --- | --- | --- |
| 必然 | 条件满足必出；可跳过 UI 说明但不可跳剧情强制遇 | 「今天本来就会撞上」 | D2 吴便装必遇；日接夜交未履约视同失败 |
| 概率 | 条件满足后按权重抽样；须有可见预警或原因 | 「最近阴气沉，今晚单更凶也不奇怪」 | H≥12 抬 risk 权重；Tn≥5 夜里待接栏可 2 张 |
| 主动招惹 | 玩家点接/拒/加价/揭穿/进脏料等之后才进入 | 「是我点的」 | 接顶格；拒被盯；日间揭穿吴；确认香火店特价脏料 |

**禁止：** 无预兆、与当前资源状态无关的「随机走廊惊吓」作为主路径事件。无订单宿主**不**再作为高压事件的硬禁止条件（已拍板推翻原默认）；无宿主高压须走第2.3.3节预告、第2.3.4节日随机上限，顶格另须 ≥D6。

#### 2.3.3 可预见性与预警（硬规则）

每条可配事件必须至少满足下列之一，否则不得进主池：

1. **接单可见**：禁忌条、risk、被盯角标、日接夜交角标、顶格预告。  
2. **白天可打听**：渠道可揭 1 条有效情报（隐忌/传播风险/转介预警）。  
3. **环境预警**：紧张态灯、街谈换套、纸马童半句、落锁仪式文案。  
4. **玩家刚做的选择**：拒被盯、脏料确认、揭穿、压下留把柄——余波写明「因何而起」。

预警强度【示例】：普通夜 / 纯冷幽默 1 句弱预兆即可；**高压与顶格必须先给预告**（已拍板，强制）：高压至少 1 层可见预告后才可遭遇；顶格至少 2 层预警（排期预告 + 接单静文案或柳提示）。未完成强制预告的高压/顶格条目不得进主池、不得在当次遭遇。

#### 2.3.4 日随机事件上限（已拍板）

**铁律：** 计入「随机事件」的条目，每个游戏日最多 **3** 次。

**计数口径**（规则已拍板；边界举例标【示例】，配关时可调表达式、不可调「每日 ≤3」这条上限本身）：

| 是否计入当日随机配额 | 范围 |
| --- | --- |
| 计入 | ① **无订单宿主**的事件（含无宿主高压/顶格，以及无单的白天紧张态高压等）；② `trigger_type = weight` 的**概率抽样**事件，且既非必然、也非主动招惹 |
| 不另计、不占满该配额 | 挂订单或人物宿主的**履约内嵌套岔路**（隐忌揭示、压下、跑路、手段回合分支等）——仍按履约原逻辑发生，不另计一次随机事件 |
| 默认不计入【示例】 | 必然事件（教学必遇、日接夜交未履约视同失败等）；主动招惹且已有订单/人物宿主的事件（接顶格、拒被盯、日间揭穿、确认脏料等「是我点的」）；昨夜已结算后挂起的次日余波展示（E-SPILL 延续，不另开一次随机） |

达上限后：当日不再抽样新的随机事件；已在进行的履约嵌套岔路、已挂起的余波、以及有宿主的必然/主动招惹仍可发生。无宿主的强制高压若与配额冲突：优先保证已承诺的必然履约；该高压延至次日或降为仅改权重与对白【示例·可调】。

配置建议：全局 `max_random_events_per_day = 3`；单条用 `counts_as_random` 显式声明是否计入（缺省按上表口径推断）。

#### 2.3.5 前置事件（已拍板扩展）

部分事件须先触发指定前置事件后才开放。配置字段 `requires_event_ids`（string[]）：所列 `event_id` 均曾成功触发（至少完成遭遇并进入结算，或配置声明的等价完成态）之前，本事件不得进池、不得遭遇。

预检顺序：教学窗 / 壳状态 → `requires_event_ids` → 日随机配额 → 其余 `trigger_expr`。前置未满足记 `weird_block.reason_code = prerequisite_unmet`。

### 2.4 事件结构模板（全文唯一）

所有主路径诡异事件共用同一生命周期。子步骤可空，但不得打乱顺序、不得跳过「结算」。

```
预兆 → 遭遇 → 决策 → 结算 → 余波
```

| 阶段 | 条件 | 系统行为 | 玩家看到 | 完成判定 |
| --- | --- | --- | --- | --- |
| 预兆 | 触发条件将满足或已满足 | 写 `omen_id`；可选街谈/黄历叙事/童半句 | 一句可忽略的不对劲或明确角标 | 预兆已展示或已记录（复玩可缩） |
| 遭遇 | 进入对应壳（柜台/夜接单/履约） | 拉起事件卡或履约现场包 | 情境、已知禁忌、主目标 | 玩家进入决策 UI |
| 决策 | 遭遇完成 | 列出 ≥2 个互咬选项；灰显给 reason | 选项、代价预览、二次确认（危险操作） | 选定并确认 |
| 结算 | 决策确认 | 按事务键写回资源/标记；播反馈 | 结算卡差分；不可改数 | 事务成功 |
| 余波 | 结算完成 | 挂延迟标记或次日具名后果 | 当日尾声句 / 次日街谈或少单 | 余波标记写入或展示完毕 |

#### 2.4.1 失败代价与可补救路径

| 失败形态 | 事件层代价（对齐 V0.3） | 可补救路径 |
| --- | --- | --- |
| 普通履约失败 | M 无或少；H+2；Ty-1；N-2；1 个具名议论【示例】 | 次日补救菜单：低价白天的单 / 送礼 / 精工 / 低 risk 夜里的单（诡异订单） |
| 顶格失败 | H+4；Ty-3；N-4；可能贴条/封门 1 日【示例】 | 封门日少单；不对劲清除条件【暂定】见 V0.3 第2.6节 |
| 压下 | 半报酬；把柄；H **默认不变**（单条可配置 +1，对齐 V0.3 B15；已拍板） | 洗把柄（每周可洗 1 次【示例】，已拍板为本稿默认）；用经营回血 |
| 跑路 | 普通失败 + Tn-1；目击者具名后果 | 同普通失败补救；Tn 靠低 risk 夜里的单回 |
| 拒被盯 | H+1；把柄约 3 游戏日【示例】（已拍板为本稿默认） | 花钱洗（每周可洗 1 次【示例】，已拍板为本稿默认）；或硬扛到期 |
| 白天轻忌外溢 | day_offense → 日末 H+=min(2,…)【示例】 | 次日少犯；洁净仪轨微降 H【示例】 |

坏结局不由单条普通事件直接跳脸；收摊检定仍走 V0.3 第4.6节。事件只负责把 H/不对劲/顶格失败等**推到检定入口**。

#### 2.4.2 与履约结构的咬合

事件决策嵌套按**履约回合制**（已拍板）：遭遇后进入手段回合；事件「选项」可以是手段选择、主目标分支、或中途岔路（压下/跑路）。结算口径不变。

三槽方案（开场一次填槽）仅为历史备选，本稿不再随其切换写法。V0.3 主方案若仍将夜履约结构标为【暂定】，以主方案文本为准；事件层嵌套按回合制实现。

### 2.5 调性与文案规范（事件专用）

| 规则 | 内容 |
| --- | --- |
| 冷幽默位置 | 柜台圆场、错位话术、童递错、压下后的干巴收束 |
| 高压位置 | 顶格现场、隐忌揭示、街上炸锅、不对劲未清又顶格 |
| 顶格 | 冷幽默收束默认关闭；文案更静；选项更少 |
| 尺度 | 发忌 / 盯梢 / 错身 / 纸人自行；少血腥；不照搬宗教仪轨写实 |
| 「那侧」烈度 | 跟 V0.3 B13【待拍板】；未拍板前文案偏闻声见影，不正面写死 |
| 玩家文案 | 短、可执行；对白建议 ≤28 字（项目另有标准时从其标准） |
| 策划说明 | 与玩家文案分行；标准文案用 TextID |

**玩家可见文案示范（冷幽默）：**

- 柜台（阿杰想闪光灯）：「拍完发群里，您这纸人可精神。」→ 选项「请关闪光灯」/「……你自行」  
- 落锁翻夜页：「你以为加班做纸人。账本不同意。」  
- 纸马童递错：「他把符纸递成快递面单。面单上没地址，只有一个『夜』字。」

**玩家可见文案示范（偶发高压）：**

- 履约隐忌揭示：「第三人在场。刚才门外那一声，不算人。」  
- 顶格静句：「灯还在。人先别动。」  
- 次日外溢：「群里有人问：纸扎铺是不是晚上不做活人生意了。」

### 2.6 容错与恢复（引用 V0.3 第2.5节）

事件层不另定义恢复口径。要点：

- 履约中途退出 → 回夜接单；不鼓励现场重 roll。  
- 履约现场禁存【暂定·推荐】。  
- 结算连点按事务键幂等。  
- 坏结局 → 上一日日初；无「本场履约重来」。

## 3. 核心流程

### 3.1 玩家在一个游戏日里会碰到怎样的「诡异」

| 时段 | 事件如何出现 | 主要感到 | 关键取舍 |
| --- | --- | --- | --- |
| 白天 | 轻忌、错位预告、打听、脏料确认、余波街谈 | 稳、冷幽默；诡异在台面下 | 要不要打听；要不要脏料；要不要揭穿 |
| 落锁 | 翻夜页仪式；日末轻忌入 H；日接夜交入待办 | 「加班做纸人」冷一句 | 未交白天的单是否硬落锁 |
| 夜接单 | 夜里待接栏、被盯、童引、顶格角标 | 报酬高、规矩狠 | 接/拒/加价；少接降压 vs 拒被盯 |
| 夜履约 | E-FULFILL 主战场；Threat 三件套 | 偶发高压 | 规矩/道具/人情；压下/跑路/硬撑 |
| 收摊～次日 | 结算写回；E-SPILL 余波 | 夜里搞砸白天补 | 补救还是硬扛再接 |

### 3.2 事件状态机（挂在 V0.3 壳上，不新增壳）

| 事件状态 | 开始条件 | 表现 | 结束条件 |
| --- | --- | --- | --- |
| `OMEN` | 触发预检通过 | 角标/街谈/童句/黄历叙事 | 进入遭遇或游戏日结束未遭遇（记「未遂预兆」【示例】） |
| `ENCOUNTER` | 玩家进入允许壳 | 事件卡或履约包 | 进入决策 |
| `CHOICE` | 遭遇完成 | 选项列表；灰显+reason | 确认选项 |
| `SETTLE` | 确认 | 结算卡；事务键 | 写回成功 |
| `AFTERMATH` | 结算成功 | 尾句或挂延迟标记 | 标记写入；次日可再展示 |
| `CLOSED` | 余波完成或无效化 | — | 可归档 |

覆盖优先级：坏结局检定与强制教学步 > 事件遭遇；恢复后显示最新结算结果。

### 3.3 高层主流程表

| 编号 | 阶段 | 触发条件 | 核心结果 | 规则来源 |
| --- | --- | --- | --- | --- |
| 1 | 日初扫描 | 进入 `DAY_SHOP` | 刷新余波展示、紧张态灯、可触发白天事件权重 | 第2.3、4.5、4.8 节 |
| 2 | 白天经营中事件 | 接谈/工艺/进货/打听/铺务 | 轻忌、脏料确认、错位预告、承诺催讨 | 第4.1～4.3、4.7 节 |

| 4 | 夜接单事件 | `NIGHT_BOARD` | 被盯/童引/顶格预告；接拒加价 | 第4.3、4.4、4.6 节 |

### 3.4 单事件标准流程（条件—行为—结果）

1. **预检：** 读壳状态、教学窗、互斥旗；不通过则不进池。  
2. **预兆：** 写 omen；展示强度按 risk/peak。  
3. **遭遇：** 展示情境、已知禁忌、主目标；顶格静音冷幽默。  
4. **决策：** ≥2 选项；预览代价；危险二次确认。  
5. **结算：** `txn_event_settle_{save_id}_{event_instance}` 幂等写回。  
6. **余波：** 当日尾句或 `named_consequence_ids`；经营补救仍走 V0.3。

### 3.5 与「订单」的关系（避免两套平行内容）

| 关系 | 规则 |
| --- | --- |
| 订单驱动事件 | 多数 E-FULFILL / E-BRIDGE / E-FACE 以订单实例为宿主 |
| 事件驱动订单 | 童引、甩锅、把柄到期可**生成或加权**一张夜里的单 |
| 无单事件 | 允许无订单宿主（含高压）；须预告（高压/顶格强制）、计入日随机配额（≤3/日），且不另开闹鬼壳或独立操作循环 |
| 配关原则 | 先定脸与 tags，再挂事件包；无单顶格允许但须 ≥D6、强制预告、计入日随机配额 |

## 4. 阶段 / 功能细节

> 每类含：玩家场景、开放条件、入口、核心循环、失败恢复；并给至少 1 条完整决策示例。数值均为【示例】。

### 4.1 E-FACE 日夜错位遭遇

**玩家场景：** 白天刚听完合规话术，夜里同一张脸便装塞红包；冷幽默与凉意同帧。

**开放条件：** 对应脸已出场；教学窗 D2 起吴便装必遇（V0.3 第4.11节）。

**入口：** 白天柜台接谈 / 夜接单立位 / 日接夜交履约。

**核心循环：** 预兆（日间话术或打听）→ 夜遭遇同一脸 → 守密/拿捏/揭穿/正经履约 → 结算双口碑差分 → 余波（吴退夜里待接栏或 `wu_secret`）。

#### 完整决策示例：吴支书便装安魂（D2 样板）

**情境：** 日间刚做完「合规净宅」宣传口径；夜里吴便装到夜里那本账，要安魂，重忌：不可录音、不可第三人。

| 选项 | 代价 | 回报 | 谁会选 |
| --- | --- | --- | --- |
| A 接并守密履约 | 耗 S/C；走履约；守密 | M+；Tn+1；`wu_secret`【示例】 | Tn 饥渴、想养夜客户 |
| B 接但日间拿捏 | 可能双跌；可勒索 1 单日接夜交 | 短期 M+；失败则 Ty/Tn 双伤 | 现金紧、爱赌 |
| C 拒（非被盯时可） | Tn 不涨；可能丢线 | 今夜减压 | 料/洁净不够、怕顶格化 |
| D 日间揭穿（若已积累） | Tn-3；吴退夜里待接栏；Ty+2【示例】 | 阳爽、夜少客户 | Ty 低、想走阳面经营 |

无单一最优：缺 C 时 A 稳；M 紧且有把柄胃口时 B 香；走「正经铺」路线 D 可能更顺。

**失败恢复：** 履约失败 → 次日抽查/强制低价白天的单；揭穿后不再出吴的夜里的单。

**文案示范：**  
夜：「便装。红包。他说这事『不好立案』。」  
选项 B 确认：「拿捏成功前，先问自己夜里还缺不缺他。」

### 4.2 E-FULFILL 履约现场发忌

**玩家场景：** 短现场；规矩/道具/人情压 Threat；隐忌中途翻出最疼。

**开放条件：** 已接夜里的单或日接夜交（`bridge`）；进入 `NIGHT_FULFILL`。

**入口：** 赴约。

**核心循环：** 进现场 → 揭示未打听 hidden → 手段回合（履约回合制）→ 主目标 → 胜/压下/败/跑路。

**Threat 初值【示例】**（引用 V0.3）：  
`Threat0 = risk + clamp(H/6,0,2) + (替代料?1:0) + (顶格?2:0)` clamp 1～5。

#### 完整决策示例：纸人自行善后（普通夜）

**情境：** 客人说纸人「自己坐直了」。主目标：封门/安座。可知忌：勿直呼真名。隐藏忌（未打听）：勿开第三盏灯。

| 选项/手段路径 | 代价 | 回报 | 资源态取舍 |
| --- | --- | --- | --- |
| 正统规矩（C≥4 且柳已教） | -C【示例】 | Threat-2；稳 | C 足、要稳 Tn |
| 歪办糊弄 | 易 H+ | Threat 弱压 | C 脏铺只剩歪办 |
| 脏料道具 | Threat-1 但 H+1 | 省正料 | S 紧、敢抬 H |
| 叫柳卡 | 欠愿或 F-2 | Threat-3；揭隐忌 | 顶格前留卡 vs 现在用 |
| 压下 | 双倍人情或指定代价；留把柄 | 强制过关半报酬 | 回合将尽、保铺优先 |
| 跑路 | Tn-1；目击者后果 | 活着收摊 | N 低、伙计在场怕崩 |

「明显最优」不存在：有柳卡但后面要顶格时，现在用卡可能更亏；脏铺时正统全灰，只能在歪办/跑路/压下里咬。

**失败恢复：** 单笔结算后回夜接单；收摊前清待办；次日补救。

**文案示范：**  
隐忌揭示：「第三盏灯亮了。纸人的脸转向灯，不是转向你。」  
跑路确认：「跑可以。镇口有人眼熟你。」

### 4.3 E-WATCH 被盯与把柄

**玩家场景：** 有的单不理也记你；洗把柄像疏通，不是无敌盾。

**开放条件：** 夜里待接栏出现 `watched_flag`；或 H≥12 强制 ≥1 被盯【示例】。

**入口：** 夜列表角标；账本/铺务洗把柄入口【暂定】。

#### 完整决策示例：拒被盯

| 选项 | 代价 | 回报 | 取舍 |
| --- | --- | --- | --- |
| 接并履约 | 耗资源；可能 risk 偏高 | 消被盯；可能 Tn+ | 料够就消化 |
| 拒 | H+1；把柄约 3 游戏日【示例】（已拍板为本稿默认） | 今夜不耗履约 | 今夜顶格/料崩时的「赊账」 |
| 加价接 | risk+1；报酬↑ | 钱多险大 | M 紧且自信 |
| 白天花钱洗（若已有把柄） | M【示例】；每周可洗 1 次【示例】（已拍板为本稿默认） | 清把柄 | 有钱无胆时 |

把柄到期未洗 → 加权凶单或 E-OATH 催讨（见第4.9节）。

### 4.4 E-BRIDGE 日接夜交翻转

**玩家场景：** 白天收订金、开阳面说法；夜里必须办真阴事。

**开放条件：** 白天接日接夜交（`bridge`）；落锁后置顶待办。【频率【暂定】重要剧情脸每 2～3 游戏日 ≤1】

**铁律（已拍板）：** 日接夜交默认**不计**入被盯。拒办其阴面，按普通失败结算，不按被盯或拒被盯处理。

**入口：** 接谈时勾选日接夜交（`bridge`）；夜待办置顶。

#### 完整决策示例：白天净宅宣传 / 夜安魂

| 选项 | 代价 | 回报 | 取舍 |
| --- | --- | --- | --- |
| 日收订金并夜履约成功 | 夜耗 S/C/手段 | 订金+尾款；错位叙事完成 | 标准路径 |
| 日收订金夜未履约 | 视同普通夜失败 | — | 禁止「只收订金不办事」白嫖 |
| 白天拒日接夜交 | 可能轻伤介绍关系；若已接后拒办阴面，按普通失败（不计被盯） | 今夜无强制阴 | 料不足时 |

冷幽默：「宣传单写『科学净宅』。夜里科学先睡了。」

### 4.5 E-SPILL 次日外溢余波

**玩家场景：** 失败变成「谁在议论你」；经营感靠「还能补」。

**开放条件：** 昨夜结算写入 `named_consequence_ids`。

**入口：** 日初街谈、少单、抽查、封门贴条、伙计台词、补救菜单。

#### 完整决策示例：阿杰夜失败 → 短视频传闻

| 次日选项 | 代价 | 回报 | 取舍 |
| --- | --- | --- | --- |
| 低价白天的单 ×2 补救 | AP/交期 | 回 M | 紧巴时先活 |
| 送礼安抚传播链 | M 或 F | 压传闻权重【示例】 | 保 Ty |
| 主动接阿杰阳面改装单圆场 | 耗 AP | Ty 微回；可能再触发轻忌 | 爱用人情线 |
| 不理 | 阳刷新 -1 持续【示例】 | 省当日动作 | 只适 Ty 仍高 |

固定入口句沿用 V0.3：「白天还能补」。

### 4.6 E-TONG 纸马童相关

**玩家场景：** 白天像摆设；夜里接待带路引单；身份通关前模糊。

**开放条件：** 夜里；童引单约 Tn≥3 或剧情旗【示例】。后期组随 V0.3 B4 终局枝裁剪（已拍板）：终局未拍板前，后期组按可裁剪占位；旧愿枝启用时后期组进池。通关前身份仍模糊。

**入口：** 夜接待立位；带路检；递错冷幽默。

#### 完整决策示例：童引一张夜里「不该寻」的单

| 选项 | 代价 | 回报 | 取舍 |
| --- | --- | --- | --- |
| 跟童走并履约 | 高 risk 可能 | Tn+；童信任；可能旧愿进度【暂定】 | 养线 |
| 拒童引 | 童信任不涨；可能错失信物窗 | 今夜减压 | 教学窗或料崩 |
| 追问「你到底是什么」 | 模糊回绝；无揭穿 | 氛围 | 过早追问不给剧透 |
| 用「纸马童带路」卡 | 耗卡 | 跳过 1 迷路/错身检 | 履约中险段 |

**不做：** 战斗宠；通关前身份实锤。

### 4.7 E-INCENSE 香火店相关（常驻开启时才进池）

**玩家场景：** 对门抢单压价；夜里甩锅共背；便宜料偶发脏标签。

**开放条件：** 香火店为常驻（`incense_shop_enabled` 为真）时本类才进 E-INCENSE 池；否则整类权重归零、不进池（已拍板，随 V0.3 B5）。

**入口：** 街巷进货；夜甩锅单；竞争周标签【扩展】。

#### 完整决策示例：特价脏料捆

| 选项 | 代价 | 回报 | 取舍 |
| --- | --- | --- | --- |
| 二次确认买入 | 8M→+5S；概率 dirty【示例】 | 料够接单 | 紧巴 |
| 不买 | — | 无脏风险 | C/H 已紧时 |
| 买林医生洁净料 | 更贵；C+ | 正统门票 | 要走正统夜 |
| 接甩锅夜里的单共背 | 风险共担；失败具名可能双背 | 报酬；同行关系 | 香火店线【暂定】 |

**不做：** 灭门选项。

### 4.8 E-TENSION 紧张态显现

**玩家场景：** 灯色发冷、日客发虚、夜里的单变凶；不是 HUD 数字尖叫。

**开放条件：** 对应紧张态成立（V0.3 第3.8节）。

**入口：** 紧张态灯说明；街谈换套；夜里待接栏权重；洁净仪轨铺务。

| 状态 | 事件层表现【建议】 | 玩家可做什么 |
| --- | --- | --- |
| 镇子发虚 H≥12 | 日客台词发虚；夜 risk 权重↑；强制 ≥1 被盯【示例】 | 少接、打听、洗把柄、成功履约降 H |
| 街上炸锅 H≥18 | 强制顶格候选；近坏结局 | 优先降 H/清不对劲；避免再顶格失败 |
| 脏铺 C<4 | 正统锁定；履约事件选项变窄 | 白天洁净仪轨/精工/林料 |
| 没人帮 | 人情槽硬扛 | 送礼回 F；做人情线拿卡 |

此类**不**另开闹鬼壳或独立操作循环；默认可只改权重、对白、可选手段与预兆密度。无订单宿主的紧张态高压事件允许出现，须强制预告，并计入第2.3.4节日随机配额。街上炸锅强制顶格候选仍须 ≥D6、先给预告；若当日随机配额已满，按第2.3.4节冲突处理【示例】。
